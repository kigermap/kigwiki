# Recent Kigurumi Collection

This section groups verifiable public kigurumi material by month: events, daily life, discussion, craft, safety, etiquette, education, and academic research. Annual chronicles are closed only after the material stabilizes.

## Workflow

1. Maintain one page per calendar month.
2. Keep the most complete version of a repeated event.
3. Label announcements and post-event reports separately.
4. Leave a domain empty when no relevant item can be verified.
5. Move only unique, stable facts into an annual volume.
