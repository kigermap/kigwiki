## 分类边界

收录 animegao kigurumi 的**人脸／动漫角色头壳**制作业务，包括全定制、半定制、量产、DIY 素体及同店相关配件。软质 PVC 人脸面具也属于这一范围，不以材料软硬机械区分。

**Furry 兽头、kemono 兽装、furkig 动物脸、吉祥物头套、连体睡衣、普通乳胶或硅胶面具不归入本目录。** 检查实际造型、说明和用途，不只依赖标题中的“kigurumi”。人类脸配猫耳、精灵耳的动漫角色不因此自动变成 furry。

混合经营商家只记录符合范围的产品。HiDolls 的 HD09 Animal 系列、BHY 动物风格固定型号及母品牌的非相关用品不并入人脸头壳价目表。

## 营业状态口径

| 标记 | 本轮证据 | 不能据此推出 |
| --- | --- | --- |
| 公开销售 | 第一方有商品、价格和购买入口 | 保证有库存、排期或完成交易 |
| 接受询价 | 第一方明确提供商业委托与询价方式 | 所有角色都接、可立即付订金 |
| 周期抽选 | 第一方说明定期受理与抽选 | 当前申请一定成功 |
| 暂停定制 | 第一方明确写 Closed | 该经营主体永久停业或没有现货 |
| 接单待核实 | 有制作身份或历史作品记录，缺少当前接单证据 | 仍在接单、旧联系方式有效 |

默认显示前三类；“全部档案”可查看暂停与待核实记录。Kigurumi Sensei 的“十月重开”没有年份，不推定已恢复。SIGMA、KigCos 等未标近期修订日期的价格，保留网页报价说明，并以最新询价为准。核实日期是**访问日期**，不是发布或修订日期。

## 跨平台去重

| 证据 | 处理 |
| --- | --- |
| 官网直接链接电商店铺或业务账号 | 确认为渠道；保存 URL 与来源 |
| 同主体品牌矩阵 | 合并经营主体，保留子品牌与产品线 |
| 仅同名、同图或第三方称有关联 | 标候选关联，不自动合并商品、联系方式和状态 |
| 代理、分销、代购与二手卖家 | 与原制作方分开；不是同一主体 |
| 使用其他工坊素体 | 供应方与改妆工作室分别记录 |
| 新旧资料冲突 | 当前明确第一方声明优先，保留旧信息日期 |

- **莓萌 / 拼好头 / 绘面**：官网明确同属虹野物联，合并；绘面没有已核实商品，不编造价格。

- **MidDreamKigu / KigLover**：现官网明确更名，合并旧名；Etsy LuckyKigJP 仍是历史候选关联。

## 价格口径

保留 CNY、JPY、USD、GBP、HKD、EUR 原币，不跨币种做最低价排名。**整头、无假发本体、素体、订金、尾款、运费与配置加价**分别记录；同店多条报价不是多家店，角色展示也不一定是库存。

“未公开”表示本次证据不足，不代表免费。活动价与起价标明性质，售罄不写成现货。工艺、材料、工期、售后为店铺公开说明的整理，不是本站测试结果。
