# Satellite Door · サテライトドア

[返回线下体验目录](../index.md)

**复核日期：2026-09-11 · 官方发布体验与预约规则，实际档期需联系确认。**

Satellite Door 的 kigurumi 体验业务提供面具、肌タイツ、服装、鞋与小物租赁，强调享受变身的过程。官方说明拍摄并非专业摄影服务，不能以专业商业摄影成片作为默认承诺。总网站、体验专站和同名社交账号按同一主体整理。[S1、S4]

## 体验风格与业务

这里的变身体验由场地与多种租赁项目组合而成。访客可按条件租用人脸面具、全身肌タイツ、假发及衣装，再搭配鞋和小物。不同面具与衣装的费用分别计算，因此选择基础动漫脸造型，或选择 Dollkii 娃娃风格造型，会影响总价。[S1、S2]

官网展示了多种室内拍摄背景，另设背景介绍页，方便事先了解照片的氛围。照片中的花卉与帷幔可以作为风格参考；具体可用背景、服装尺码及搭配应在预约时确认。店家强调的是亲自体验变身和留影，而非保证交付商业摄影作品。[S1、S6]

官网另介绍至少已有两次到访经历的回访者可咨询户外拍摄，具体安排及限制以对应菜单为准。第一次体验应先阅读“无介绍人”规则，不能按相册里的多人或户外场景直接预约同样方案。[S1、S3]

币种为 **JPY（日元）**。以下是官网分项报价，不能把场地费当作全部体验费用；页面未明确说明税费。

| 项目 | 公开价格与条件 | 来源 |
| --- | --- | --- |
| 单人场地，最多 5 小时 | 平日 5,000；周末及节假日 6,000 | S1、S2 |
| 单人场地，超过 5 小时 | 平日 7,000；周末及节假日 8,000；首页写最长 8 小时 | S1、S2 |
| 无介绍人附加费 | 在通常费用之外加 5,000，仅接受单人首次预约 | S2、S3 |
| 全身肌タイツ | 2,000／件 | S2 |
| 上半身肌タイツ | 1,000／件；具体搭配需确认 | S2 |
| むに面（Muni 面具） | 1,000／个；同面具换假发另加 1,000 | S2 |
| あしかさめ制作「レヴ」面具 | 3,000／个 | S2 |
| 河妖屋 Dollkii 面具 | 5,000／个；同面具换假发另加 1,000 | S2 |
| Light 衣装 | 同租面具与肌タイツ时 2,000；自带其中之一时 3,000；每次最多一套 | S2 |
| Standard 衣装 | 4,000／套 | S2 |
| Premium 衣装 | 6,000／套 | S2 |

**计算示例，不是店家发布的固定套餐**：单人平日、5 小时以内、无介绍人、租全身肌タイツ＋Muni 面具＋Light 衣装，按以上分项相加为 **15,000 JPY**（5,000＋5,000＋2,000＋1,000＋2,000）。是否适用及最终总价须向店家确认。[S2、S3]

自带服装仍可能有按套收费；超过 5 小时的使用要求两套以上衣装。官网另有双人价格、视频制作、发型整理等项目，不能将这些视为默认包含在场地费内。[S2]

## 复核与分类说明

头围 60 cm 以上可能无法使用部分面具。料金页列肌タイツ SS／S／M／L，首次预约页另称至 3L，两处表述存在差异，不能据此保证特定尺码有库存。[S2、S3]

店家还有女性限定 Lolita 体验及已标注结束的季节性「ケモノ着ぐるみ」项目。本条只整理人脸面具变身体验，兽装项目不计入 kigurumi 人脸体验套餐。[S1、S4]
