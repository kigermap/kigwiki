# 2019 年 Kigurumi 编年史

> 2020–2025 年已经完成。本轮按“完成年份不重复、每次只向前整理一年”的规则，整理 2019 年。可核验的一手材料集中在 AnimeJapan 的官方角色着ぐるみ出现与公共 cosplay 基础设施；没有可靠日期的专门聚会不以推测补写。

## 资料边界

本文讨论 animegao kigurumi、官方 IP 着ぐるみ和它们直接使用的更衣、寄存、摄影与公共展示条件。FGO 官方公告可确认展位项目；AnimeJapan 官方页可确认展会日期、地点与 cosplay 区域。参与者照片、搜索摘要和无日期活动档案仅作后续线索。

## 主要纪事

### 3 月 23–24 日：FGO 在 AnimeJapan 2019 明列着ぐるみ／官方 cosplayer 登场

Fate/Grand Order 官方公告确认 AnimeJapan 2019 于 3 月 23–24 日在东京 Big Sight 举行，FGO 展位设在东 6 Hall J73；3 月 11 日的追加说明将“着ぐるみ／オフィシャルコスプレイヤーの登場”列为展位项目。[^fgo-aj]

这是可直接写入的官方 kigurumi 节点：来源没有把它称作 animegao 专门活动，因此本文不替它扩大定义；但它明确证明官方角色着ぐるみ在公共动漫展会中被安排为可见的展位节目。

### 同期：Cosplayers World 提供公共参与基础设施

AnimeJapan 2019 官方 Cosplayers World 页面确认活动在东京 Big Sight 东 1–8 Hall 举行，并设有 cosplay 参与安排。[^aj-cosplay] 该来源本身不证明每位参与者都是 kigurumi performer，但它记录了全头套实践所依赖的公共条件：进入展场、更衣、携带与摄影的组织空间。

因此 2019 的结论不是“综合 cosplay 展会等于 kigurumi 聚会”，而是官方 IP 着ぐるみ展示与一般 cosplay 基础设施在同一公共场域相交。

## 去重、空白与结论

本文只保留 2019 年的实际官方出现和场地条件。2020 年的 FGO 计划取消、2021 年的混合恢复，以及 2022–2025 年的 greeting、专门活动和安全规则均由各自年度卷承担。现存专门活动档案若没有可核日期、地点与结果，不从后续编号反推至 2019。

2019 年最稳妥的记录是：官方角色着ぐるみ已被作为大型公开展会的明确项目，而公共 cosplay 区域构成了这种实践可被展示、观看与组织的相邻基础设施。这一层不等于专门社群史的全貌，资料空白继续保留待考。
