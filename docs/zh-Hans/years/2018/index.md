# 2018 年 Kigurumi 编年史

> 2019-2025 年已经完成。本轮按“完成年份不重复、每次只向前整理一年”的规则整理 2018 年。可核验材料集中在公共活动对着ぐるみ的安全与摄影规则，以及 animegao 面具制作匹配服务的学位研究；没有可靠日期的专门聚会不以推测补写。

## 资料边界

本文只把来源明确写出的日期、场地、规则和论文元数据当作事实。AnimeJapan 是综合动漫展，并非 animegao 专门活动；它的价值在于规则直接提到着ぐるみ、面具、视野、陪同、摄影与更衣。庆应义塾大学机构库则确认了一篇直接研究 animegao kigurumi 面具制作与订单匹配的 2018 学年度硕士论文。

## 主要纪事

### 3 月 24-25 日：AnimeJapan 2018 扩展着ぐるみ公共场地规则

AnimeJapan 2018 的公众开放日于 3 月 24-25 日在东京 Big Sight 东 1-8 Hall 举行。Cosplayers World 分布在东 3、东 8 Hall，提供付费 cosplay 登记、更衣室、寄存、室内外摄影区、早场更衣与巡游。[^aj-outline][^aj-cosplay]

限制视野和行动的服装只能在 cosplay 区域穿着、摄影需获同意、更衣室禁止拍摄等基础规则在 2017 年已经出现，详见[2017 年卷](../2017/index.md)。2018 年可单独确认的更新是场地扩展至东 3、东 8 Hall，并在巡游规则中要求着ぐるみ或遮挡视线的头部装具必须由一名陪同人员照看。[^aj-cosplay]

同页延续拍摄前取得同意、不得强迫姿势、不得在更衣室拍摄和使用寄存处等要求。本文不把这些延续条款重复计算为 2018 年新制度；本年的独有节点是更大场地和明确的巡游陪同责任。

### 2018 学年度：animegao 面具制作进入学位研究

庆应义塾大学机构库收录地曳はるか的硕士论文《アニメ顔着ぐるみマスク制作マッチングサービスの構築：マスク受注販売事業「キグルミ屋」の活動を通じて》，导师为杉浦一徳，出版者为庆应义塾大学大学院媒体设计研究科，形态为 x + 65 页，并标为 2018 学年度媒体设计学第 689 号。[^keio][^ndl]

论文题名本身确认研究对象是 animegao kigurumi 面具制作、制作者匹配与“キグルミ屋”受注销售活动。由于机构库没有公开摘要，本文不推断其方法、样本或成效；只记录一个可核验的知识生产节点：面具制作供需与服务设计已经成为正式硕士研究主题。

## 去重、空白与结论

本卷不重复 2019 年 FGO 官方着ぐるみ登场、2020 年取消与线上化、2021 年混合恢复，也不倒写 2022-2025 年的专门活动、Doll Weekend、官方 greeting 与后续规则。2018 年未找到一手来源足以确认日期、地点和结果的专门 animegao 聚会，因此保留为空白。

2018 年最稳妥的结论有两层：公共活动在既有视野、行动与摄影边界上增加了巡游陪同责任；面具制作的订单和制作者匹配则进入大学学位研究。一个节点来自现场治理的增量，一个节点来自知识与产业组织，二者共同构成不夸大的年度记录。
