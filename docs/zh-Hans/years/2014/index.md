# 2014 年 Kigurumi 编年史

2014 年的材料从公共动漫展扩展到艺术摄影。Laurie Simmons 的作品档案明确以 Kigurumi、Dollers 为系列题目；AnimeJapan 则记录官方角色互动与公共摄影设施。

## 年度重点

- **艺术摄影**：Laurie Simmons 的《Kigurumi, Dollers and How We See》标为 2014 年。
- **3 月 22–23 日**：AnimeJapan Family Park 安排角色着ぐるみ互动。
- **公共摄影**：室内布景、室外摄影区和服装租赁实际运行。[^simmons][^aj-report]

## 年度纪事

### 3 月 22-23 日：Family Park 的角色着ぐるみ进入公开互动环节

AnimeJapan 2014 于 3 月 22-23 日在东京 Big Sight 东 1-6 Hall 举行。主办方报告记载，Family Park 的互动舞台安排哆啦 A 梦、Keroro 军曹等角色着ぐるみ依次登场。现场有家庭、成年动画观众和情侣参加合影与握手；相邻的纪念摄影区还陈列了蜡笔小新与浣熊拉斯卡尔等角色玩偶。[^aj-report]

这条记录属于官方角色 / mascot 语境，不等同于 animegao 玩家活动。它的编年价值在于确认：角色着ぐるみ在 2014 年的综合动漫展中已被组织成面向公众、以合影和握手为核心的互动节目。

### 3 月 22-23 日：Cosplayers World 的室内外摄影基础设施实际运行

同一份闭幕后报告确认，Cosplayers World 同时设置室内和室外摄影区。室内区提供与《舰队Collection》《进击的巨人》《魔法少女小圆》等作品联动的布景和背景板；室外区聚集了动画、游戏与漫画 cosplayer 和摄影者，并记录到海外参与者。活动还在 ACOS 与 COSPA 协力下提供每小时 1,000 日元的服装租赁，降低首次 cosplay 的进入门槛。[^aj-report]

### 年内作品：Laurie Simmons 的 Kigurumi / Dollers 摄影系列

艺术家官网将《Kigurumi, Dollers and How We See》归为 2014 年，并分别列出《Yellow Hair/Red Coat/Umbrella/Snow》《Orange Hair/Snow/Close Up》等照片，以及同名展示的现场视图。[^simmons]

该系列将角色面貌、假发色彩、服装、身体姿态及室内外场景用于艺术摄影。它属于艺术家的作品与展示档案，不能当作爱好者聚会报道；同一系列的多张照片合并为一项年度作品记录。

原图和展示视图可从艺术家官网查看。该站并未授予本站开放转载许可，因此本卷提供原始作品入口。

## 年度小结

本年展示了两种不同的公开呈现：官方角色在动漫展面向观众互动，Kigurumi / Dollers 也成为艺术摄影题材。艺术系列、商业角色与普通 cosplay 场域分别记录，保留各自的来源和性质。
