# 2014 年 Kigurumi 编年史

> 2015-2025 年已经完成。本轮依照“已完成年份不重复、每次只向前整理一年”的规则，只整理 2014 年。可核验的一手材料集中在 AnimeJapan 2014 的主办方闭幕后报告；没有可靠日期、地点和结果的专门聚会不以推测补写。

## 1. 取材边界

本卷采用 AnimeJapan 主办方保存的 2014 年闭幕后报告。报告能够确认活动日期、场地、官方角色着ぐるみ互动，以及 Cosplayers World 的室内外摄影区和服装租赁确实运行。[^aj-report]

AnimeJapan 是综合动漫展，不是 animegao kigurumi 专门活动。报告把哆啦 A 梦与 Keroro 军曹等角色明确写作“着ぐるみ”，但没有把 Cosplayers World 的普通参与者识别为 animegao。本文因此把**官方角色着ぐるみ**与**可供全头角色扮演使用的公共 cosplay 基础设施**分开记录，不把普通 cosplay 照片或全场人流推定为 animegao 参与证据。

## 2. 可核验节点

### 3 月 22-23 日：Family Park 的角色着ぐるみ进入公开互动环节

AnimeJapan 2014 于 3 月 22-23 日在东京 Big Sight 东 1-6 Hall 举行。主办方报告记载，Family Park 的互动舞台安排哆啦 A 梦、Keroro 军曹等角色着ぐるみ依次登场。现场有家庭、成年动画观众和情侣参加合影与握手；相邻的纪念摄影区还陈列了蜡笔小新与浣熊拉斯卡尔等角色玩偶。[^aj-report]

这条记录属于官方角色 / mascot 语境，不等同于 animegao 玩家活动。它的编年价值在于确认：角色着ぐるみ在 2014 年的综合动漫展中已被组织成面向公众、以合影和握手为核心的互动节目。

### 3 月 22-23 日：Cosplayers World 的室内外摄影基础设施实际运行

同一份闭幕后报告确认，Cosplayers World 同时设置室内和室外摄影区。室内区提供与《舰队Collection》《进击的巨人》《魔法少女小圆》等作品联动的布景和背景板；室外区聚集了动画、游戏与漫画 cosplayer 和摄影者，并记录到海外参与者。活动还在 ACOS 与 COSPA 协力下提供每小时 1,000 日元的服装租赁，降低首次 cosplay 的进入门槛。[^aj-report]

这些设施并未证明现场存在 animegao kigurumi，也没有提供着ぐるみ参与人数。本文只把它们作为 2015 年“更衣室与室外区域较上一年扩大”之前的可核验基线：2014 年已存在室内外摄影空间和公共参与服务，2015 年卷则保留扩容、收费、移动和摄影规则等新增事实。

现有编年、日常 / 杂谈与百科 / 科普框架足以承载这些资料。同一综合展中的两个相关环节不足以另建独立活动、工坊或学术板块。

## 5. 年度结论

2014 年可确认的不是一份 animegao 专门活动清单，而是两种不同的公共实践：官方角色着ぐるみ在 Family Park 承担合影与握手互动；Cosplayers World 的室内外摄影区、作品布景和服装租赁则构成普通 cosplay 的公共参与基础。两者必须分开表述。主办方报告能证明这些设施和节目实际运行，却不能证明 animegao 参与者、专门聚会或社群规模；这些资料空白继续保留。
