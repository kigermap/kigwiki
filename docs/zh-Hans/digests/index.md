## 为什么单独建立这个板块

近期资料会持续更新，若直接写进年度长文，容易产生重复、未完结结论和多语言版本漂移。本站采用“月度采集 → 来源复核 → 年度归档”的流程：

1. 同一自然月只维护一个页面，不按天复制页面。
2. 相同活动只保留最新、信息更完整的一条。
3. 活动预告和活动回顾分开标注，不把预告写成已经发生。
4. 没有可核验新内容的领域明确写“本月未收录”，不使用无关资料填充。
5. 月度页成熟后，才把独有事实整理进相应年度编年。

## 固定领域

| 领域 | 收录范围 |
| --- | --- |
| 编年史 | 有明确日期、地点与来源的公共节点 |
| 日常 / 杂谈 | 公开活动记录、参与观察、社区讨论 |
| 工坊 / 手工 | 面具、眼片、假发、内衬、服装与维护技术 |
| 百科 / 科普 | 术语、历史、健康、安全与材料知识 |
| 礼仪 | 摄影同意、接触边界、公开发布与场地规则 |
| 学术 | 直接相关且可核验的论文、调查或研究资料 |

## 编辑边界

匿名指控、私人聊天、未授权照片、详细地址和无法确认日期的转述不会作为事实发布。第三方图片默认只链接原始来源，不复制到本站；本站自制图表只概括已引用的公开信息。
