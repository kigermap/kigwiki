# Недавние материалы о Kigurumi

В этом разделе по месяцам собраны проверяемые открытые материалы о kigurumi: события, повседневность, обсуждения, изготовление, безопасность, этикет, просветительские и академические публикации. Годовая хроника закрывается только после стабилизации сведений.

## Порядок работы

1. Для одного календарного месяца поддерживается одна страница.
2. Повторяющиеся сообщения об одном событии объединяются в наиболее полную запись.
3. Анонсы и отчеты о состоявшихся событиях отмечаются отдельно.
4. Направление остается пустым, если новых подтвержденных материалов нет.
5. В годовой том переносятся только уникальные и устойчивые факты.
