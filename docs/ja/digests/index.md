# Kigurumi 近期収集

公開確認できる kigurumi 関連のイベント、日常、議論、制作、安全、礼儀、啓発、学術資料を月ごとにまとめる。年次編年は情報が安定してから確定する。

## 運用

1. 一つの暦月につき一ページだけを更新する。
2. 同一イベントは最も完全な記録に統合する。
3. 予告と終了後の報告を区別する。
4. 確認できる新情報がない分野は空欄にする。
5. 固有で安定した事実だけを年次編年へ移す。
