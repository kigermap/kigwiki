# 2019年 Kigurumi 編年史

> 2020–2025年は完成済みである。一回につき一年前へ進む方針により、本稿は2019年のみを扱う。一次資料は AnimeJapan における公式キャラクター着ぐるみの登場と、隣接する公共コスプレ基盤に集中する。日付未確認の専門イベントは事実にしない。

## 資料範囲

animegao kigurumi、公式 IP 着ぐるみ、および更衣、携行、撮影、公開展示の条件を対象とする。FGO 公式告知はブース企画を、AnimeJapan 公式ページは会場とコスプレ区域を確認する。参加者写真や日付のないアーカイブは手がかりにとどめる。

## 確認できる年表

### 3月23–24日：FGO が AnimeJapan 2019 で着ぐるみ／公式コスプレイヤー登場を明記

Fate/Grand Order の公式告知は AnimeJapan 2019 が3月23–24日に東京ビッグサイトで行われ、FGO ブースが東6ホール J73 に置かれたことを確認する。3月11日の追記は「着ぐるみ／オフィシャルコスプレイヤーの登場」をブース企画として明記した。[^fgo-aj]

これは公式着ぐるみの直接資料である。ただし出典は専門 animegao イベントとは呼んでいないため、本文もそのように拡張しない。公共アニメイベントにおける公式キャラクター着ぐるみの展示として記録する。

### 同時期：Cosplayers World という隣接する公共基盤

AnimeJapan の Cosplayers World ページは東京ビッグサイト東1–8ホールでの開催とコスプレ参加の仕組みを確認する。[^aj-cosplay] これは全参加者を kigurumi performer とする証拠ではないが、全頭型実践が依存しうる入場、更衣、携行、撮影の公共条件を示す。

## 重複排除と結論

本稿は2019年の公式登場と会場文脈のみを残す。2020年のFGO企画中止、2021年のハイブリッド回復、2022–2025年の greeting、専門イベント、安全規則は各年の巻に委ねる。日付、場所、結果を確認できない専門ページは後年の番号から2019年へ遡及しない。

最も堅い結論は、公式キャラクター着ぐるみがすでに公開アニメイベントの明示的な企画であり、総合コスプレ基盤が隣接する活動環境を構成していたことである。専門社群史全体と同一視せず、残る空白は調査課題として保存する。
