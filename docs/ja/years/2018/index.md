# 2018年 Kigurumi 編年史

> 2019-2025年は整理済みである。「完成年を重複させず、一回につき一年前へ進む」という規則に従い、本巻は2018年だけを扱う。確認できる資料は、公共イベントにおける着ぐるみの安全・撮影規則と、animegao マスク制作マッチングサービスの学位研究に集中している。日付のない専門イベント情報は事実化しない。

## 資料の範囲

日付、会場、規則、論文メタデータが出典に明記された事項のみを採用する。AnimeJapan は総合アニメイベントであり animegao 専門イベントではないが、規則が着ぐるみ、仮面、視界、アテンド、撮影、更衣を直接扱う。慶應義塾大学の機関リポジトリは、animegao kigurumi マスクの制作と受注マッチングを直接扱った2018年度修士論文を確認できる。

## 確認できた編年

### 3月24-25日：AnimeJapan 2018 が着ぐるみの公共会場規則を拡張

AnimeJapan 2018 のパブリックデイは3月24-25日に東京ビッグサイト東1-8ホールで開催された。Cosplayers World は東3・東8ホールを使用し、有料のコスプレ登録、更衣室、クローク、屋内外撮影エリア、早朝更衣室、パレードを設けた。[^aj-outline][^aj-cosplay]

視界・移動を制限する衣装の cosplay エリア限定、撮影同意、更衣室のプライバシーという基礎規則は2017年にすでに存在した。詳細は[2017年巻](../2017/index.md)を参照。2018年に独自に確認できる更新は、東3・東8ホールへの会場拡張と、パレードで着ぐるみや視界を遮る被り物を使う参加者に一名のアテンドを必須とした点である。[^aj-cosplay]

同ページは撮影同意、ポーズの非強制、更衣室内の撮影禁止、クローク利用を継続した。本巻は継続条項を2018年の新制度として重複計上せず、会場拡張と明確なパレード・アテンド責任を当年固有の節点とする。

### 2018年度：animegao マスク制作が学位研究の対象になる

慶應義塾大学学術情報リポジトリは、地曳はるかの修士論文『アニメ顔着ぐるみマスク制作マッチングサービスの構築：マスク受注販売事業「キグルミ屋」の活動を通じて』を収録する。指導は杉浦一徳、出版者は慶應義塾大学大学院メディアデザイン研究科、形態は x + 65頁で、2018年度メディアデザイン学第689号とされる。[^keio][^ndl]

題名から、animegao kigurumi マスクの制作、制作者マッチング、「キグルミ屋」の受注販売活動が研究対象だったことまでは確認できる。リポジトリに抄録がないため、方法、標本、成果は推定しない。制作の需給、受注、サービス設計が正式な修士研究テーマになったという範囲で記録する。

## 重複排除・空白・結論

2019年の FGO 公式着ぐるみ登場、2020年の中止とオンライン化、2021年のハイブリッド再開、2022-2025年の専門イベント、Doll Weekend、公式 greeting、後年の規則は繰り返さない。2018年の専門 animegao 集会について、日付・場所・結果をそろえて確認できる一次資料は見つからなかったため、空白を保持する。

2018年について最も堅実な結論は二つある。公共イベントは既存の視界、移動、撮影境界にパレードのアテンド責任を加え、マスク制作の受注と制作者マッチングは大学院研究に入った。前者は現場運営の増分、後者は知識と生産組織の節点であり、証拠を拡大せずに年度像を構成する。
