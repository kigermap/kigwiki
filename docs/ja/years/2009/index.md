# 2009年 Kigurumi 編年史

> 2004年の公式規定を補録したため、本巻は2009年を大型着ぐるみ、更衣、クローク、撮影同意の最初の明文時点とはしない。2009年に新しい、または独立して検証できる手荷物検査計画、裁縫道具、受付時限、閉幕確認だけを残す。

## 1. 取材範囲

公式開催概要は9月24-25日をビジネスデイ、9月26-27日を一般公開日とし、会場を幕張メッセとしている。本巻は開催概要、来場注意事項、9月27日の開催結果を用い、事前公表規定と閉幕後に確認された展示会全体を区別する。[^tgs-overview][^tgs-rules][^tgs-report]

これは総合ゲーム展示会であり、animegao kigurumi の専門イベントではない。規定は引き続き「大きな着ぐるみ」を記すが、animegao の参加者、人数、演目、実来場結果は示さない。2004年と共通する衣装、更衣、保管、撮影条項は逐条反復しない。

## 2. 検証可能な節点

### 9月26-27日：一般公開日の手荷物検査計画が cosplay 参加者を含む

主催者は両一般公開日に手荷物検査を実施すると告知し、荷物が多い cosplay 参加予定者には入場時間の余裕を求めた。持込禁止品には、50センチを超える cosplay 用の傘、杖、ラケットなどと、他者を傷つけ得る鋭利・危険物が含まれた。[^tgs-rules]

これは cosplay の荷物が当年の公開安全計画に入ったことを示す。検査完了報告ではなく、animegao または大型着ぐるみ参加者が実際に検査を受けた証拠でもない。

### 9月26-27日：共同規定が継続し、裁縫道具と受付時限が加わる

2009年規定は、通行を妨げる「大きな着ぐるみ」の制限、クローク込み500円の指定更衣、出口の衣装確認、指定撮影区域、被写体許可、個人サイト掲載同意を継続した。共同条項は[2004年巻](../2004/index.md)へ移し、継続を新制度として扱わない。[^tgs-rules]

2009年に独立して残す運用情報は、スタッフから裁縫道具を借りられたことと、更衣室受付が16:00までだったことである。[^tgs-rules] 応急維持と時間管理の情報であり、工房や制作講座の証拠ではない。

### 9月27日：開催結果が展示会全体の閉幕を確認

主催者の結果報告は東京ゲームショウ2009が9月24-27日に開催・閉幕したことを確認するが、cosplay 企画、大型着ぐるみ、animegao の参加を個別には報告しない。[^tgs-report]

## 3. 分野判定

| 分野 | 2009年に検証できる内容 | 編集判断 |
| --- | --- | --- |
| 編年史 | TGS の日程、会場、一般公開日、閉幕確認 | 年度主軸へ収録 |
| 日常 / 雑談 | 裁縫道具と16:00の受付時限 | 参加手順の補足として収録 |
| 工房 / 制作 | 応急道具だけで制作発表なし | 工房項目を作らない |
| 百科 / 解説 | 大型着ぐるみ共同規定は2004年まで遡れる | 早年巻へ接続し反復しない |
| 礼儀 / 安全 | 当年の手荷物検査計画と危険物境界 | 収録 |
| 学術 | 2009年の直接関連する検証可能な新研究なし | 収録しない |

既存区分で十分であり、独立したイベント、工房、学術区分は設けない。

## 4. 年度間の重複排除

| 継続テーマ | 2009年に残す内容 | 他年度の扱い |
| --- | --- | --- |
| 大型着ぐるみと撮影同意 | 2009年の継続だけを確認 | 共同規定全文は2004年に残す |
| 更衣とクローク | 裁縫道具、16:00受付時限 | 2004年は基礎手順、2010-2011年は会場変化 |
| 手荷物と小道具安全 | 一般公開日の検査計画 | 50センチ一般上限を2009年の新規則として反復しない |
| 実参加 | animegao と大型着ぐるみ到場証拠空白を維持 | 規則や総来場者数から推計しない |

## 5. 年度結論

2009年の独自記録は、一般公開日の手荷物検査計画と、更衣手順における裁縫道具、16:00受付時限である。大型着ぐるみ、指定更衣、保管、撮影同意は2004年公式規定ですでに検証できるため、ここでは継続だけを記す。閉幕報告は展示会全体を確認するが、該当形態の参加を証明しない。
