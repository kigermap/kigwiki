# 2009年 Kigurumi 編年史

> 2010-2025年巻は完成済みである。「完成年を作り直さず、1回につき過去1年だけ進める」という規則に従い、本巻は2009年だけを追加する。検証可能な一次資料は東京ゲームショウ2009の主催者アーカイブに集中しており、確かな日付・場所・結果のない専門集会を後年資料から再構成しない。

## 1. 取材境界

東京ゲームショウ2009の公式開催概要は、9月24-25日をビジネスデイ、9月26-27日を一般公開日、会場を幕張メッセとしている。本巻は主催者の開催概要、来場注意事項、9月27日の開催結果を用い、公表規定と閉幕後に確認された展示会全体を区別する。[^tgs-overview][^tgs-rules][^tgs-report]

東京ゲームショウは総合ゲーム展示会であり、animegao kigurumi 専門イベントではない。規定は「大きな着ぐるみ」を直接記すが、animegao の参加者、人数、演目、実来場結果は示さない。本巻は**公共展示会における大型着ぐるみの明文境界と隣接する参加手順**だけを記録し、一般 cosplay 規定や総来場者数を kigurumi 来場証拠に置き換えない。

## 2. 検証可能な節点

### 9月26-27日：一般公開日の手荷物検査計画が cosplay 参加者を含んだ

主催者は両一般公開日に手荷物検査を実施すると告知し、荷物が多い cosplay 参加予定者には入場時間の余裕を求めた。持込禁止品には、50センチを超える cosplay 用の傘、杖、ラケットなどと、他者を傷つけ得る鋭利・危険物が含まれた。[^tgs-rules]

これは主催者が cosplay の荷物と小道具を公開安全計画に含めたことを示す。検査完了報告ではなく、animegao または大型着ぐるみ参加者が実際に検査を受けた証拠でも、専門集会の記録でもない。

### 9月26-27日：規定が大型着ぐるみを明記した

衣装規定は「大きな着ぐるみ」、大型ハリボテ、床を引きずるスカートやマントを周囲の迷惑になる衣装として挙げ、違反時には cosplay 中止を求める場合があるとした。この表現は大きさ、通行、公共安全の境界であり、animegao、公式キャラクタースーツ、すべての kigurumi の同義分類ではない。[^tgs-rules]

開催結果は東京ゲームショウ2009が9月24-27日に開催・閉幕したことを確認するが、cosplay 企画や大型着ぐるみ参加を個別には報告しない。「規定が存在したこと」と「その形態の参加者が来場したこと」は分けて扱う。[^tgs-report]

### 9月26-27日：更衣、クローク、撮影同意が公開手順を構成した

指定更衣室はクローク込み500円で、他所での更衣、更衣室内の飲食・休憩・撮影を禁止した。出口で衣装確認を行い、衣装を着た来退場を認めず、スタッフが裁縫道具を貸し出した。更衣室受付は16:00までとされた。[^tgs-rules]

撮影は3・4ホール間の「やすらぎのモール」の一部だけで認められ、被写体の許可と、無関係な来場者を写さない壁背景を求めた。営利撮影、出版物への投稿、写真売買を禁止し、個人サイト掲載にも事前説明と許可を必要とした。[^tgs-rules]

## 4. 2010-2025年との重複排除

| 継続テーマ | 2009年に残す内容 | 後年の扱い |
| --- | --- | --- |
| 大型着ぐるみ規定 | 現在完成済みの巻でより早い明文時点と、大きさ / 通行の文脈 | 2010-2011年は継続だけを示し、新規規定として繰り返さない |
| 更衣とクローク | 500円、指定更衣、衣装確認、裁縫道具 | 2010年は7ホール、早朝利用、夜間延長；2011年は2ホール移動を残す |
| 撮影と伝播 | やすらぎのモール、被写体許可、壁背景、非営利境界 | 後年は場所、動画、公開規則の実質変化だけを残す |
| 手荷物と小道具安全 | 一般公開日の検査計画と50センチ上限 | 規定が変わらない限り、後年巻で一般注意を繰り返さない |

## 5. 年度結論

2009年に安定して記録できるのは、東京ゲームショウが大型着ぐるみ、cosplay の荷物、指定更衣、クローク、撮影同意を公共展示会規定に含めたことである。開催結果は展示会全体を確認するが、animegao または大型着ぐるみ参加者の来場は証明しない。2010年巻は、新設された一体的 cosplay 企画、7ホールの早朝更衣、Dance Night 延長という実質変化だけを残す。
