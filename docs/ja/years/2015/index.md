# 2015年 Kigurumi 編年史

> 2016-2025年は整理済みである。「完成年を重複させず、一回につき一年前へ進む」という規則に従い、本巻は2015年だけを扱う。確認可能な一次資料は AnimeJapan の公共 cosplay 基盤に集中している。日付、場所、実施結果を確認できない専門イベントは事実化しない。

## 1. 資料の境界

本巻は AnimeJapan 主催者が保存する開催概要、Cosplayers World 規則、開催レポートだけを用いる。これらは日付、会場、着ぐるみを明記した規則、関連設備が実際に運用されたことを確認できる。

AnimeJapan は総合アニメイベントであり、animegao kigurumi 専門イベントではない。総来場者数は kigurumi 参加者数ではなく、一般 cosplay の会場写真から animegao 参加を推定することもできない。本巻が記録するのは、公共会場での kigurumi 参加を支えるエリア、更衣、荷物保管、移動補助、撮影の運営条件である。

## 2. 確認できる節点

### 3月21-22日：AnimeJapan 2015 が着ぐるみを含む公共 cosplay 空間を拡張

AnimeJapan 2015 のパブリックデイは3月21-22日に東京ビッグサイト東1-6ホールで開催された。Cosplayers World は屋内外 cosplay エリア、有料登録、更衣室、クローク、作品公式撮影セットを提供し、主催者は更衣室と屋外エリアを前年より拡張したと説明した。[^aj-outline][^aj-cosplay]

cosplay 登録料は一日500円だった。更衣室は10:00-17:00、早朝利用は7:00-9:00。クロークは別料金の一日500円で、当日中の再出入が可能、利用は16:30までだった。屋内 cosplay エリアは16:30、屋外エリアは16:00まで利用できた。[^aj-cosplay] 面、衣装、付属品を運ぶ kigurumi 参加者にとって、時間、料金、荷物への再アクセスは公共参加の実用条件である。

規則は大型造形、着ぐるみ、ドール類を屋内外 cosplay エリアに限定した。視界または移動を制限する衣装は、移動時に外す、抱える、介助人を付けるなどして周囲の通行を妨げないよう求められた。撮影は指定エリアに限り、被写体の許可を必要とし、ポーズの強制を認めなかった。更衣室内ではカメラ、携帯電話、スマートフォンによる撮影が禁止された。[^aj-cosplay] 着ぐるみ状態の視界、移動、プライバシー、同意を直接扱う運営記録である。

### 閉幕後：開催レポートが拡張エリアと撮影設備の実運用を確認

開催レポートは AnimeJapan 2015 が3月20-22日に実施され、全体で12万人を超える来場者を集めたと確認する。この数字はビジネスエリア、パブリックエリア、全企画を含み、kigurumi 規模へ換算できない。レポートは Cosplayers World の更衣室と屋外エリアが前回より広くなり、前年より多くの cosplayer が集まったこと、作品公式セットと汎用撮影背景に列ができたことも記録する。[^aj-report]

このレポートにより、事前の規則上の計画と実際に運用された設備を区別できる。ただし、専門 kigurumi 集会、特定 animegao キャラクター、着ぐるみ参加者数は証明しないため、公共イベント基盤の実施記録として扱う。

## 4. 2016-2025年との重複整理

| 継続主題 | 2015年に残す内容 | 後年の扱い |
| --- | --- | --- |
| AnimeJapan 公共設備 | 2014年より拡張した更衣室・屋外区、別料金の登録とクローク | 2016年は当年新設の臨時屋外区、一体化した登録サービス、開催後の確認だけを残す |
| 移動と介助 | 視界・移動制限時の取り外し、抱持、介助人という選択肢 | 2018年はパレード場面のより強い必須アテンド要件を残し、2015年へ遡及しない |
| 撮影とプライバシー | 指定区域、撮影許可、ポーズ強制禁止、更衣室撮影禁止 | 後年は新設または変更された制度文だけを残す |
| 公式 IP / 専門イベント | 十分な一次資料なし | 2019-2025年の確認済み節点を遡及しない |

## 5. 年次結論

2015年の確実な記録は専門イベント一覧ではなく、実運用が確認できる公共 cosplay 空間の拡張である。AnimeJapan は着ぐるみ、ドール、大型造形、視界制限衣装をエリアと移動管理の対象として明記し、更衣、保管、撮影エリア、同意の境界を用意した。開催レポートは拡張設備が使われたことを確認する。後年の拡大から2015年の空白を逆算しない。
