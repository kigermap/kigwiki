# 2005年 Kigurumi 編年史

> 本巻は当年の出来事、作品、公開資料を記録します。告知、開催記録、資料の発表を区別します。

## 検証可能な節点

### 5月16日：主催者がテーマ、日程、目標を発表

リリースは「最前列で、未来を見よう。」というテーマ、ビジネスデイ、2日間の一般公開、幕張会場、入場料、目標規模を掲載した。[^tgs-release] 確認できるのは2005年の公共展示会の計画背景までで、kigurumi 専門条項や参加記録はない。

### 9月16-18日：公式予定期間、完了状態は未確認

主催者トップページも9月16-18日と幕張会場を示す。[^tgs-home] 今回の調査では検証可能な閉幕後総括を取得できなかったため、「公式予定期間」として記録し、「全日程完了」とはしない。animegao または大型着ぐるみの来場を示す証拠もない。
