# 2005年 Kigurumi 編年史

> 2006-2025年は整理済みである。「完了年を作り直さず、1回につき1年だけ遡る」という規則に従い、本巻は2005年のみを扱う。現存する主催者アーカイブから確認できるのは東京ゲームショウ2005の予定日程と会場までであり、直接引用できる kigurumi / cosplay 規定、実参加、閉幕結果は得られない。そのため2006年資料を遡及せず、証拠境界を記録する。

## 1. 取材境界

主催者トップページは会期を9月16-18日、会場を日本コンベンションセンター（幕張メッセ）とする。5月16日のリリースは9月16日をビジネスデイ、17-18日を一般公開日と分け、来場15万人、出展130社、1,500小間を**目標値**として掲げる。[^tgs-home][^tgs-release]

これらは総合ゲーム展の出展・概要資料であり、animegao kigurumi の活動記録ではない。目標値は最終実績ではなく、予定日程だけで全プログラムの完了も証明できない。閲覧可能な資料は大型着ぐるみ、マスク型 cosplay、指定更衣、撮影同意、実参加を直接記していないため、隣接概念、出展者キャラクター、翌年規定を2005年へ補入しない。

## 2. 検証可能な節点

### 5月16日：主催者がテーマ、日程、目標を発表

リリースは「最前列で、未来を見よう。」というテーマ、ビジネスデイ、2日間の一般公開、幕張会場、入場料、目標規模を掲載した。[^tgs-release] 確認できるのは2005年の公共展示会の計画背景までで、kigurumi 専門条項や参加記録はない。

### 9月16-18日：公式予定期間、完了状態は未確認

主催者トップページも9月16-18日と幕張会場を示す。[^tgs-home] 今回の調査では検証可能な閉幕後総括を取得できなかったため、「公式予定期間」として記録し、「全日程完了」とはしない。animegao または大型着ぐるみの来場を示す証拠もない。

## 3. 分野判断

| 分野 | 2005年の検証可能資料 | 編集判断 |
| --- | --- | --- |
| 編年史 | 主催者の予定日程、一般公開日、会場 | 証拠境界として収録 |
| 日常 / 雑談 | 当年の検証可能な公開記録なし | 収録しない |
| 工房 / 制作 | 検証可能な制作発表なし | 収録しない |
| 百科 / 啓発 | 目標値、実績値、翌年規定を混同しない | 出典説明として収録 |
| 礼儀 / 安全 | 当年の kigurumi / cosplay 規定を取得できず | 2006年から遡及しない |
| 学術 | Crossref と OpenAlex に2005年の直接関連記録なし | 収録しない |

既存の編年史と出典境界で十分であり、イベント、工房、人物、学術の新設区分は設けない。再利用許諾が不明な第三者写真も転載しない。

## 4. 2006-2025年との重複排除

| 継続主題 | 2005年巻に残す内容 | 後続年の扱い |
| --- | --- | --- |
| TGS 公共背景 | 予定日程、一般公開日、会場 | 2006年以降は当年の新規かつ検証可能な規定・結果だけを残す |
| 大型着ぐるみ規定 | 証拠空白 | 閲覧可能な最初の明文は2006年に残し、遡及しない |
| 更衣、保管、撮影 | 証拠空白 | 2006年巻に指定更衣、クローク、確認、撮影同意の基準を残す |

## 5. 年度結論

2005年に安定して記録できるのは、主催者が公表した東京ゲームショウの予定日程、一般公開日、幕張会場である。閲覧可能な資料は kigurumi / animegao の実参加、専門規定、開催完了を証明しない。この空白を明記する方が2006年規定の複製より正確である。次の未整理年は2004年となる。
