# 2013年 Kigurumi 編年史

> 2014-2025年は整理済みである。「整理済みの年を重複せず、一回につき過去一年だけ進める」という方針に従い、本巻は2013年のみを扱う。アクセス可能な一次資料は東京ゲームショウ2013の主催者規則アーカイブに集中している。日付、場所、結果を確認できない専門集会は推測で補わない。

## 1. 資料の境界

本巻は東京ゲームショウ2013の公式アーカイブに残る日本語・英語の cosplay 参加案内を用いる。そこから開催日、会場、主催者が当時公表した衣装、更衣、移動、撮影、画像公開の条件を確認できる。[^tgs-rules]

東京ゲームショウは総合ゲーム展示会であり、animegao kigurumi の専門イベントではない。日本語規則は「大きな着ぐるみ」を直接挙げるが、具体的な animegao 参加者、専門集会、参加人数は特定しない。本巻が記録するのは、**公共イベントが大型着ぐるみと隣接する cosplay 基盤をどのように管理したか**である。一般 cosplay、全体来場者数、規則の存在そのものを animegao 参加の証拠にはしない。

## 2. 検証済みノード

### 9月19-22日：大きな着ぐるみが公共イベントの衣装境界に入る

東京ゲームショウ2013の公式アーカイブは、9月19-20日をビジネスデイ、9月21-22日を一般公開日、会場を幕張メッセと記す。cosplayer 向け規則は「大きな着ぐるみ」、ハリボテ、床を引きずるスカートやマントを周囲の迷惑になる衣装として列挙した。スカートとマントは撮影時のみ広げることができ、移動時には畳む必要があった。英語版は該当区分を “large size full-body suits” と訳している。[^tgs-rules]

これはすべての着ぐるみを禁止する規則ではなく、会場にどの面具キャラクターがいたかも示さない。検証できる範囲は、2013年までに大規模な公共ゲーム展示会が大型着ぐるみを通行空間と周囲への影響に関わる衣装管理対象として明記していたことである。

### 9月21-22日：更衣、指定撮影区域、画像公開同意を一つの参加条件に統合

同じページは、更衣を9ホールの cosplay 更衣室に限定し、トイレなど他の場所での更衣を禁じ、更衣室内の飲食、休憩、撮影も禁止した。海浜幕張駅の始発から8:00までの早朝更衣、クローク利用上の注意、costume を着たままの来退場禁止も告知している。[^tgs-rules]

撮影は9ホール内外と指定駐車場区域に限定され、撮影前には対象者の許可が必要だった。個人サイトへ画像を掲載する場合も関係者の承認を求めている。公式アーカイブは条件の公表を証明するが、開催後報告ではないため、各設備が予定どおり運用されたことや kigurumi 参加者が実際に利用したことまでは証明しない。

## 4. 2014-2025年との重複排除

| 継続テーマ | 2013年に残す内容 | 後年の扱い |
| --- | --- | --- |
| 公共イベントの着ぐるみ | 東京ゲームショウによる大型着ぐるみの空間制限 | 2014年は AnimeJapan の公式キャラクター交流、2015年は別イベントの着ぐるみ / doll 区域・移動規則を残す |
| 更衣と保管 | 9ホール更衣室、早朝時間、クローク条件 | 後年は別イベントの新料金、設備拡張、運用結果だけを残す |
| 撮影と公開同意 | 撮影前許可と個人サイト公開前の再同意 | 後年は新しい公開経路、商用制限、より具体的なプライバシー規則を残す |
| animegao 専門イベント | 十分な一次確認なし | 後年イベントを2013年へ遡及しない |

## 5. 年度結論

2013年に安定して書けるのは animegao 専門イベント一覧ではなく、公共イベントの境界である。東京ゲームショウは大型着ぐるみを通行・空間管理に含め、更衣室、クローク、指定撮影区域、撮影許可、画像公開同意を同時に公表した。この規則は着ぐるみが大規模公共 cosplay 場域の管理語彙に入っていたことを示すが、特定参加者、専門集会、設備の実利用、コミュニティ規模を証明しない。その空白は残す。
