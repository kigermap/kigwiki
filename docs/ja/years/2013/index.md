# 2013年 Kigurumi 編年史

> 本巻は当年の出来事、作品、公開資料を記録します。告知、開催記録、資料の発表を区別します。

## 検証済みノード

### 9月19-22日：大きな着ぐるみが公共イベントの衣装境界に入る

東京ゲームショウ2013の公式アーカイブは、9月19-20日をビジネスデイ、9月21-22日を一般公開日、会場を幕張メッセと記す。cosplayer 向け規則は「大きな着ぐるみ」、ハリボテ、床を引きずるスカートやマントを周囲の迷惑になる衣装として列挙した。スカートとマントは撮影時のみ広げることができ、移動時には畳む必要があった。英語版は該当区分を “large size full-body suits” と訳している。[^tgs-rules]

これはすべての着ぐるみを禁止する規則ではなく、会場にどの面具キャラクターがいたかも示さない。検証できる範囲は、2013年までに大規模な公共ゲーム展示会が大型着ぐるみを通行空間と周囲への影響に関わる衣装管理対象として明記していたことである。

### 9月21-22日：更衣、指定撮影区域、画像公開同意を一つの参加条件に統合

同じページは、更衣を9ホールの cosplay 更衣室に限定し、トイレなど他の場所での更衣を禁じ、更衣室内の飲食、休憩、撮影も禁止した。海浜幕張駅の始発から8:00までの早朝更衣、クローク利用上の注意、costume を着たままの来退場禁止も告知している。[^tgs-rules]

撮影は9ホール内外と指定駐車場区域に限定され、撮影前には対象者の許可が必要だった。個人サイトへ画像を掲載する場合も関係者の承認を求めている。公式アーカイブは条件の公表を証明するが、開催後報告ではないため、各設備が予定どおり運用されたことや kigurumi 参加者が実際に利用したことまでは証明しない。
