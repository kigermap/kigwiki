# 1999年 Kigurumi 編年史

> 2000-2025年は整理済みである。「完了年を繰り返さず、1回につき1年だけ遡る」という規則に従い、本巻は1999年だけを追加する。東京ゲームショウ30周年公式史は春・秋開催の日程、来場者数、春のステージ企画を確認できるが、写真、企画、統計のどれにも kigurumi / animegao という注記はない。本巻は後年から補完せず、同時期の公共背景と証拠境界を記録する。

## 1. 取材境界

公式史は1999年春を第6回、3月19-21日、来場者163,448人とし、イベントステージで CESA クイズ王決定戦を実施したと記す。第7回の秋は9月17-19日、来場者163,866人である。[^tgs-history] 主催者の回顧記録として、開催と記載されたステージ企画の実施を確認できる。

同じページには両開催の写真とポスターがあるが、人物、衣装分類、kigurumi / animegao 参加の個別説明はない。総来場者数、一般ステージ企画、説明のない写真だけでは、専門規定、コミュニティ参加、特定の演者を証明できない。画像の再利用許可も明示されていないため、本巻は出典をリンクし、素材を転載しない。

Inside Doll の一次ホームページと更新履歴はいずれも専門サイトの公開開始を2003年に置くが、具体日には矛盾がある。[^inside-main][^inside-news] これらは同サイトを1999年へ前倒しできないことを示すだけで、同年に別の実践、個人サイト、活動がなかったことを証明しない。

## 2. 検証可能な節点

### 3月19-21日：TGS 1999 春の完了記録

公式30周年史は第6回を「1999年・春」とし、3月19-21日、163,448人、CESA クイズ王決定戦を記録する。[^tgs-history] これは公共イベントと一般企画の背景であり、kigurumi 参加記録ではない。

### 9月17-19日：TGS 1999 秋の完了記録

同じ公式ページは第7回を「1999年・秋」とし、9月17-19日、163,866人を記録する。[^tgs-history] この数字は展示会全体のもので、関連衣装分類の規模、初出、完了状態を示さない。

### 後年の専門出版と規定を前倒ししない

[2003年巻](../2003/index.md)に Inside Doll の公開開始を残し、[2004年巻](../2004/index.md)に現在最初に直接検証できる大型着ぐるみ公共規定を残す。どちらも1999年へ移さず、公式写真の未説明人物を特定の装演分類へ割り当てない。

| 日常 / 雑談 | 同年の専門記録を検証できない | 後年の回想や現在の検索結果で補わない |

| 百科 / 科普 | 開催記録、一般企画、総来場者数は kigurumi 参加証拠ではない | 証拠説明として収録 |
| 礼儀 / 安全 | 同年の kigurumi / cosplay 専門規定を検証できない | 後年の規定から推測しない |

年度編年と証拠説明で十分であり、二つの隣接公共イベントから独立した活動、工房、人物、学術部門は作らない。

## 4. 2000-2025年との重複排除

| 継続テーマ | 1999年に残す内容 | 後続年での扱い |
| --- | --- | --- |
| TGS 公共背景 | 両開催の日程、来場者数、春のステージ企画、証拠境界 | 2000年は次の2開催と累計100万人の節目、2004年は直接引用できる大型着ぐるみ規定を保持 |
| 専門ウェブ出版 | 2003年の開始記録を前倒ししない | Inside Doll の開始は2003年だけに残す |
| 現実参加 | 同年の面、演者、工房、参加人数の証拠空白 | 総来場者数、未説明写真、後年規定から推定しない |
| 画像 | 再利用許可が明確でない公式写真をコピーせずリンクだけを置く | 許可と検証可能な説明が得られた場合のみ再評価 |

## 5. 年度結論

1999年に安定して記録できるのは、東京ゲームショウ春・秋の実施日、主催者回顧の来場者数、春のステージ企画と、それらが kigurumi / animegao 専門規定や参加を証明しないという境界である。2003年の専門サイトと2004年の公共規定は出典年に残す。次の未整理年は1998年である。
