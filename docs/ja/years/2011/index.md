# 2011年 Kigurumi 編年史

> 2012-2025年は整理済みである。「完了年を再収録せず、1回につき過去1年だけ進める」という方針に従い、本巻は2011年のみを扱う。確認できる一次資料は東京ゲームショウ2011の主催者アーカイブに集中している。日時、場所、結果を確かめられない専門交流会を後年の資料から推測して補わない。

## 1. 取材範囲

東京ゲームショウ2011の公式開催概要は、9月15-16日をビジネスデイ、9月17-18日を一般公開日、会場を幕張メッセとしている。本巻は主催者が保存する日本語・英語のコスプレ参加規定から、衣装、更衣、クローク、移動、撮影について当年公表された条件を確認する。[^tgs-overview][^tgs-rules]

東京ゲームショウは総合ゲーム展示会であり、animegao kigurumi の専門イベントではない。規定は「大きな着ぐるみ」を直接挙げ、英語版は “large size full-body suits” と訳すが、animegao 参加者や人数を特定しない。別途告知された Cosplay Collection Night もコスプレファッションショーとダンスパーティーとのみ説明され、animegao または kigurumi の演目を示さない。[^tgs-event] 本巻は**公共展示会が大型着ぐるみと周辺 cosplay 基盤をどう管理したか**だけを記録し、一般 cosplay 企画や規定の存在を来場証拠へ読み替えない。

## 2. 検証可能な節点

### 9月17-18日：大型着ぐるみ規定の検証可能な基準年が2011年へ遡る

一般公開日の規定は、大型着ぐるみ、張りぼて、床を引きずるスカートやマントを、周囲の迷惑になる衣装として挙げる。日本語版は、長いスカートとマントは撮影時のみ広げ、移動時には畳むよう補足する。[^tgs-rules]

この記載は animegao の来場を証明せず、すべての kigurumi が同じ寸法リスクを持つことも意味しない。更新されるのは出典の時間境界である。2012年巻で記録した大型着ぐるみの動線規定は、同じ主催者アーカイブにより2011年まで遡って確認できる。共通文言は重ねて拡張しない。

### 9月17-18日：2ホールの更衣、クローク、早朝利用が一つの参加動線を構成

指定更衣室は2ホールにあり、500円の使用料にクロークが含まれた。トイレ等での更衣、更衣室内の飲食、休憩、撮影は禁止され、男性更衣室が一時的に女性用へ転用される場合があった。出口では衣装確認があり、参加者は16:00までに戻り、衣装のまま来退場できず、スタッフから裁縫道具を借りられた。[^tgs-rules]

更衣室は海浜幕張駅の始発から8:00まで早朝開室する予定で、更衣後は一般待機列の最後尾へ戻る運用だった。保存ページが証明するのは公表された設備と手順までであり、閉幕後報告ではないため、利用実績や animegao 参加を確定できない。

### 9月17-18日：指定撮影区域で壁を背景に第三者を除外

撮影は3・4ホール間の「やすらぎのモール」の一部と事務局指定区域に限られた。被写体の許可を得て、無関係な人を写さないため壁を背景に撮影することが求められた。会場写真の出版物への投稿・売買と営利撮影は禁止され、個人サイトへの掲載にも本人の同意が必要だった。[^tgs-rules]

2012年規定は同意と営利利用の原則を維持しつつ、更衣室を7ホール南側へ移し、会場南側の海沿い屋外撮影区域と会場全体の動画禁止を明記した。[^tgs-2012] したがって本巻は、**2ホールの動線と「壁を背景にする」2011年の空間基準**のみを残す。2012年に加わった場所と伝播の境界は2012年巻に置く。

## 4. 2012-2025年との重複排除

| 継続テーマ | 2011年に残す内容 | 後年の扱い |
| --- | --- | --- |
| 公共展示会の着ぐるみ | 現在確認できるより早い2011年の規定時点 | 2012年は最初ではなくなるが、新しい空間・画像利用境界を残す |
| 更衣とクローク | 2ホール、500円、早朝開室、男性室の一時転用 | 2012年は7ホール移動、2013年は9ホール移動を残す |
| 撮影と伝播 | やすらぎのモール、指定区域、壁背景 | 2012年は海沿い屋外区域と動画制限、後年は新規則のみ |
| 一般 cosplay 企画 | Cosplay Collection Night に animegao / kigurumi 演目の証拠なし | 約100名という説明を kigurumi 来場記録にしない |

## 5. 年度結論

2011年に安定して記録できるのは、東京ゲームショウのより早い公共参加基準である。大型着ぐるみはすでに動線規定に含まれ、2ホールでは有料更衣・クローク、早朝利用、修補道具が案内され、撮影は指定区域で壁を背景に行うよう求められた。7ホール、海沿い屋外撮影区域、動画制限は2012年の変化として本巻では繰り返さない。個別の animegao 参加者、専門交流会、設備利用数、開催結果は未確認のまま残す。
