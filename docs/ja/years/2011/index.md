# 2011年 Kigurumi 編年史

> 2009-2010年および2012-2025年は整理済みである。本ページは2009年巻の追加後に再校正し、2011年に固有の変化だけを残す。

## 1. 取材範囲

東京ゲームショウ2011の公式開催概要は、9月15-16日をビジネスデイ、9月17-18日を一般公開日、会場を幕張メッセとしている。本巻は主催者が保存する日本語・英語のコスプレ参加規定から、衣装、更衣、クローク、移動、撮影について当年公表された条件を確認する。[^tgs-overview][^tgs-rules]

東京ゲームショウは総合ゲーム展示会であり、animegao kigurumi の専門イベントではない。規定は「大きな着ぐるみ」を直接挙げ、英語版は “large size full-body suits” と訳すが、animegao 参加者や人数を特定しない。別途告知された Cosplay Collection Night もコスプレファッションショーとダンスパーティーとのみ説明され、animegao または kigurumi の演目を示さない。[^tgs-event] 本巻は**公共展示会が大型着ぐるみと周辺 cosplay 基盤をどう管理したか**だけを記録し、一般 cosplay 企画や規定の存在を来場証拠へ読み替えない。

## 2. 検証可能な節点

### 9月17-18日：大型着ぐるみ規定は2006年の境界を継続

一般公開日の規定は、大型着ぐるみ、張りぼて、床を引きずるスカートやマントを、周囲の迷惑になる衣装として挙げる。日本語版は、長いスカートとマントは撮影時のみ広げ、移動時には畳むよう補足する。[^tgs-rules]

この記載は animegao の来場を証明せず、すべての kigurumi が同じ寸法リスクを持つことも意味しない。主催者の2006年アーカイブに同じ境界があるため、2011年は継続として扱い、最初の時点または独立した新規節点とはしない。[2006年巻](../2006/index.md)を参照。

### 9月17-18日：更衣・クロークが7ホールから2ホールへ移動

2011年の実質的な空間変化は、指定更衣室が2010年の7ホールから2ホールへ移ったことである。500円、指定更衣、衣装確認は2006年に遡り、16:00までの受付と裁縫道具貸出は2009年から確認できるため、移動の文脈としてだけ残す。[^tgs-rules][^tgs-2009]

更衣室は海浜幕張駅の始発から8:00まで早朝開室する予定で、更衣後は一般待機列の最後尾へ戻る運用だった。保存ページが証明するのは公表された設備と手順までであり、閉幕後報告ではないため、利用実績や animegao 参加を確定できない。

### 9月17-18日：撮影同意と壁背景の規定を継続

撮影は3・4ホール間の「やすらぎのモール」の一部と事務局指定区域に限られた。被写体の許可を得て、無関係な人を写さないため壁を背景に撮影することが求められた。会場写真の出版物への投稿・売買と営利撮影は禁止され、個人サイトへの掲載にも本人の同意が必要だった。[^tgs-rules]

撮影区域、同意、壁背景、非営利利用の境界は2006年にすでに公表されており、2011年の新規節点とはしない。2012年規定は更衣室を7ホール南側へ戻し、会場南側の海沿い屋外撮影区域と会場全体の動画禁止を明記した。[^tgs-2012] 本巻は**2011年の2ホールへの移動**だけを残す。

## 4. 2009-2010年および2012-2025年との重複排除

| 継続テーマ | 2011年に残す内容 | 後年の扱い |
| --- | --- | --- |
| 公共展示会の着ぐるみ | 2011年は同じ規定の継続で、新規節点ではない | より早い確認点は2006年に残し、2012年は新しい空間・画像利用境界を残す |
| 更衣とクローク | 2010年の7ホールから2ホールへの移動 | 2010年は早朝利用と夜間延長、2012年は7ホール復帰、2013年は9ホール移動を残す |
| 撮影と伝播 | やすらぎのモール、同意、壁背景を継続 | 共通境界は2006年に置き、2012年は海沿い屋外区域と動画制限を残す |
| 一般 cosplay 企画 | Cosplay Collection Night に animegao / kigurumi 演目の証拠なし | 約100名という説明を kigurumi 来場記録にしない |

## 5. 年度結論

2011年に固有の安定した変化は、更衣・クロークが2010年の7ホールから2ホールへ移ったことである。大型着ぐるみ、撮影同意、壁背景、非営利利用は2006年を、早朝更衣は2010年を継続し、新規節点として繰り返さない。2012年には7ホールへ戻り、海沿い屋外撮影区域と動画制限が加わる。
