# 2011年 Kigurumi 編年史

> 本巻は当年の出来事、作品、公開資料を記録します。告知、開催記録、資料の発表を区別します。

## 検証可能な節点

### 9月17-18日：大型着ぐるみ規定は2004年の境界を継続

一般公開日の規定は、大型着ぐるみ、張りぼて、床を引きずるスカートやマントを、周囲の迷惑になる衣装として挙げる。日本語版は、長いスカートとマントは撮影時のみ広げ、移動時には畳むよう補足する。[^tgs-rules]

この記載は animegao の来場を証明せず、すべての kigurumi が同じ寸法リスクを持つことも意味しない。主催者の2004年アーカイブに同じ境界があるため、2011年は継続として扱い、最初の時点または独立した新規節点とはしない。[2004年巻](../2004/index.md)を参照。

### 9月17-18日：更衣・クロークが7ホールから2ホールへ移動

2011年の実質的な空間変化は、指定更衣室が2010年の7ホールから2ホールへ移ったことである。500円、指定更衣、衣装確認は2004年に遡り、16:00までの受付と裁縫道具貸出は2009年から確認できるため、移動の文脈としてだけ残す。[^tgs-rules][^tgs-2009]

更衣室は海浜幕張駅の始発から8:00まで早朝開室する予定で、更衣後は一般待機列の最後尾へ戻る運用だった。保存ページが証明するのは公表された設備と手順までであり、閉幕後報告ではないため、利用実績や animegao 参加を確定できない。

### 9月17-18日：撮影同意と壁背景の規定を継続

撮影は3・4ホール間の「やすらぎのモール」の一部と事務局指定区域に限られた。被写体の許可を得て、無関係な人を写さないため壁を背景に撮影することが求められた。会場写真の出版物への投稿・売買と営利撮影は禁止され、個人サイトへの掲載にも本人の同意が必要だった。[^tgs-rules]

撮影区域、同意、壁背景、非営利利用の境界は2004年にすでに公表されており、2011年の新規節点とはしない。2012年規定は更衣室を7ホール南側へ戻し、会場南側の海沿い屋外撮影区域と会場全体の動画禁止を明記した。[^tgs-2012] 本巻は**2011年の2ホールへの移動**だけを残す。
