# 2020年 Kigurumi 編年史

> 2021–2025年は完成済みである。「完成年を重複させず、一回につき一年前へ進む」という方針に従い、今回は2020年を整理する。後年の出来事から空白を逆算しない。

![2020年公開記録タイムライン](../../../assets/images/kigurumi-2020-chronicle/timeline_2020.svg)

## 0. 対象と資料基準

animegao kigurumi、美少女着ぐるみ、面型コスプレ、公式 IP 着ぐるみ、および直接利用する会場、更衣、撮影、交流、公開配信の基盤を対象とする。WCS は隣接する総合コスプレ場であり、参加者全体を kigurumi とみなす根拠にはしない。

主催者・IP 公式ページは計画、日付、中止、構成の確認に使う。参加者映像や検索要約は手がかりに限定し、確認可能な日付のないアーカイブを2020年に割り当てない。

## 1. 確認できた経過

### 1月27日、2月27日：FGO 着ぐるみ企画の告知と中止

Fate/Grand Order の AnimeJapan 2020 公式出展ページは、3月21–22日のブース企画として「コスプレイヤー／着ぐるみ」を明記していた。[^fgo-aj] 総合展示会から推測したものではなく、直接の kigurumi 記録である。

2月27日、AnimeJapan は新型コロナウイルス感染拡大、政府のイベント自粛方針、来場者と関係者の安全を理由に開催中止を決定した。FGO も同日にブース中止を追記した。[^animejapan][^fgo-aj] よって状態は「告知後に中止」であり、実施済み greeting とは記録しない。

AnimeJapan の Cosplayers World には更衣室、クローク、公式撮影背景、衣装制作企画が予定されていた。[^aj-cosplay] 全頭型参加者に必要な運搬、更衣、休憩、撮影の基盤も同時に失われたことが分かる。

### 7月1日、8月1–2日：WCS の全面オンライン化

WCS 2020 ONLINE 特設サイトは7月1日に公開された。8月1日12:00–13:00の開会式に続き、同日20:00から8月2日20:00まで24時間番組を配信した。[^wcs2020]

参加ページは、自宅から作品・テーマ別の Zoom cosplay gathering に参加し、仮想背景を使い、公式番組に出演できる仕組みを案内した。未成年者には保護者の許可を求め、収録映像がウェブ、テレビ、新聞、パンフレット、広告に再利用され得ることも明示した。[^wcs-entry]

kigurumi にとって、オンライン化は面の運搬や更衣室の負担を下げる一方、家庭内の映り込み、現実身元、録画、長期再利用という新しい同意問題を生んだ。2021年のハイブリッド開催とは別の、全面代替の段階である。

## 3. 重複除去と結論

本稿は FGO の「告知されたが中止された」着ぐるみ企画と、WCS の全面オンライン代替のみを残す。2021年のハイブリッド化と `キグルミwasshoi!`、2022年以降の実地 greeting と安全規則は各年の巻に委ねる。

2020年の核は、実地参加基盤の断絶と再設計である。会場の代わりに配信、Zoom、仮想背景、再利用可能な映像が現れた。専門記録の不足は推測で埋めず、一次資料を待つ。
