# 2008年 Kigurumi 編年史

> 2009-2025年は整理済みである。「整理済み年度を繰り返さず、一回につき過去一年のみを扱う」という方針に従い、本巻は2008年だけを追加する。現存する一次資料は東京ゲームショウ2008の日程、会場、閉幕結果を確認できるが、animegao または大型着ぐるみの参加を直接確認できる記録は示していない。そのため本巻は、公開アーカイブが証明できることとできないことを併記する。

## 1. 取材範囲

公式開催概要は10月9-10日をビジネスデイ、10月11-12日を一般公開日とし、会場を幕張メッセとしている。主催者の10月12日付報告は閉幕を確認する。[^tgs-overview][^tgs-report]

東京ゲームショウは総合ゲーム展示会であり、animegao kigurumi の専門イベントではない。現在閲覧できる公式来場者向けアーカイブは、開催概要、展示マップ、出展社、チケット、交通案内を公開するが、animegao、美少女着ぐるみ、大型着ぐるみ、更衣、撮影手順を直接記していない。[^tgs-overview][^tgs-map] ページが見つからないことは参加者がいなかった証明にはならず、2009年の規則を2008年へ遡及させることもできない。

## 2. 検証可能な節点

### 10月9-12日：東京ゲームショウ2008開催

開催概要は幕張メッセでの開催と10月11-12日の一般公開を確認する。閉幕報告は4日間の総来場者を194,288人、一般公開2日間をそれぞれ71,639人、71,166人と記録する。[^tgs-overview][^tgs-report]

この数字は総合展示会の規模だけを示し、kigurumi、animegao、cosplay の参加人数ではない。本サイトは総来場者から小規模な装いの集団を推計せず、展示マップ上の一般的なキャラクターを愛好者の kigurumi 活動と自動的に分類しない。

### 公開来場者アーカイブには引用可能な kigurumi 規則系統がまだない

2008年の来場者ナビゲーションと展示マップは公共空間を示すが、cosplay 注意事項、更衣室、クローク、撮影同意、大型着ぐるみに関する引用可能な規定を提供していない。[^tgs-overview][^tgs-map]

一方、2009年の公式注意事項は「大きな着ぐるみ」、手荷物検査、指定更衣、クローク、撮影許可を明記する。[^tgs-2009-rules] したがって本サイトは、2009年を現時点で検証可能な規則の起点として残す。2008年は後年の制度を複製せず、アーカイブの境界を記録する。

## 3. 分野判定

| 分野 | 2008年に検証できる内容 | 編集判断 |
| --- | --- | --- |
| 編年史 | TGS の日程、会場、閉幕後確認 | 隣接する公共空間の背景として収録 |
| 日常 / 雑談 | 直接関連し日付を確認できる公開記録なし | 収録しない |
| 工房 / 制作 | 検証可能な制作発表なし | 収録しない |
| 百科 / 解説 | 総来場者数は kigurumi 参加証拠の代用にならない | 証拠説明として収録 |
| 礼儀 / 安全 | 2008年アーカイブに引用可能な専門規定なし | 2009年規則を遡及しない |
| 学術 | 2008年の直接関連する検証可能な新研究なし | 収録しない |

既存の編年・出典枠で十分である。直接的な活動や制作の証拠がないため、独立したイベント、工房、人物区分は設けない。

## 4. 2009-2025年との重複排除

| 継続テーマ | 2008年に残す内容 | 2009年以降の扱い |
| --- | --- | --- |
| 公共展示環境 | TGS 2008の日程、会場、一般公開日、閉幕確認 | 2008年の総来場数を再掲しない |
| 大型着ぐるみ規則 | 現在の公式資料における証拠空白 | 2009年に最初の検証可能な明文を残す |
| 更衣・保管・撮影 | 後年規則から逆算しない | 2009年以降の実際の変化だけを記録 |
| 参加規模 | 総合展示会の人数から推計しない | 後年も直接証拠のみ採用 |

## 5. 年度結論

2008年に安定して記録できるのは、隣接する公共空間として東京ゲームショウが開催されたことである。現存する公式来場者アーカイブは animegao または大型着ぐるみの参加を証明せず、専門規則も復元できない。この空白を公開することは、2009年資料から完全に見える2008年史を作るより編年史の基準に合う。
