# 2008年 Kigurumi 編年史

> 本巻は当年の出来事、作品、公開資料を記録します。告知、開催記録、資料の発表を区別します。

## 検証可能な節点

### 10月9-12日：東京ゲームショウ2008開催

開催概要は幕張メッセでの開催と10月11-12日の一般公開を確認する。閉幕報告は4日間の総来場者を194,288人、一般公開2日間をそれぞれ71,639人、71,166人と記録する。[^tgs-overview][^tgs-report]

この数字は総合展示会の規模だけを示し、kigurumi、animegao、cosplay の参加人数ではない。本サイトは総来場者から小規模な装いの集団を推計せず、展示マップ上の一般的なキャラクターを愛好者の kigurumi 活動と自動的に分類しない。

### 公開来場者アーカイブには引用可能な kigurumi 規則系統がまだない

2008年の来場者ナビゲーションと展示マップは公共空間を示すが、cosplay 注意事項、更衣室、クローク、撮影同意、大型着ぐるみに関する引用可能な規定を提供していない。[^tgs-overview][^tgs-map]

一方、2004年の公式規定はすでに「大きな着ぐるみ」、指定更衣、クローク、撮影許可を明記し、2007年は同じ流れの継続を確認し、2009年には手荷物検査計画が加わる。[^tgs-2004-rules][^tgs-2009-rules] したがって2008年は、早期の規則と後年の追加事項の間にあるアーカイブ空白として残し、前後の制度から当年を再構成しない。
