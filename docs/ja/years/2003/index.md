# 2003年 Kigurumi 編年史

> 2004-2025年は整理済みである。「完了年を重複せず、一回につき過去一年だけ進める」という方針に従い、本巻は2003年だけを追加する。現存する一次ページから、美少女着ぐるみを主題とする専門サイトが2003年4月には公開活動中だったことを確認できる。ただし開始日は二つのページで矛盾するため、両方を残し、フィクション、ページ更新、アクセス量を現実のコミュニティ活動に置き換えない。

## 1. 調査範囲

現存する Inside Doll は、主要内容を美少女着ぐるみ中心の成人向け幻想小説と説明し、フィクションを現実の着ぐるみ演技と混同せず、危険になり得る描写を実践しないよう明記している。[^inside-main][^inside-entry] 本巻が記録するのはサイトが公開されていた事実、編集上の位置づけ、更新のリズムだけである。成人作品の本文を転載せず、作品名を現実のイベント、工芸、人物記録にせず、権利不明の画像も複製しない。

メインページのヘッダーは「2003/04/23 start」とする一方、更新履歴は4月5日に「正式公開を開始しました」と記し、4月6日、12日、20日にも更新を並べる。[^inside-main][^inside-news] 二つの一次記載から一つの正確な開始日は決められない。安定して言えるのは「2003年4月には公開活動中だった」までである。

## 2. 検証可能な記録

### 4月：専門サイトが公開更新期に入る

更新履歴は4月5日を正式公開とし、その後にリンク追加と初期の投稿を記録する。メインページは4月23日を start とする。[^inside-main][^inside-news] これは同月に美少女着ぐるみ幻想を書く公開専門空間が存在したことを示すが、どちらの日にも現実の集会、マスク制作、実演があったとは示さない。

### 5-6月：編集作品と投稿が継続して公開される

5月と6月の履歴には、オリジナル作品、投稿作品、コラム、リンク更新が続き、6月には「着ぐるみ」を含む作品名も直接現れる。[^inside-news] これは専門的な執筆・投稿の仕組みが動いていた証拠であり、物語の出来事が現実に起きた証拠ではない。

### 7-12月：年後半も可視的な更新が続く

7月5日から12月20日まで、連載、投稿、コラム、リンク更新が継続する。4月分を含め、現存履歴には2003年の日付付き通知が27件ある。[^inside-news] この数はページ記録の密度だけを表し、著者、読者、kiger、イベント、作品の独立数ではない。

## 5. 年度結論

2003年に安定して記録できるのは、少なくとも4月までに、美少女着ぐるみを明示的な主題とする日本語専門サイトが公開活動中であり、その年を通じて編集・投稿通知を続けたことである。これは初期の専門ネット文化が可視化されていた証拠であり、現実の実演、工房での制作、オフ会、参加規模の証明ではない。開始日の矛盾は未解決のまま残す。次の未整理年は2002年である。
