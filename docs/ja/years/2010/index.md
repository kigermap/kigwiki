# 2010年 Kigurumi 編年史

> 2009年巻が追加された。本校勘は共通規定をより早い証拠点へ移し、2010年の実質変化だけを残す。日時、場所、結果を確かめられない専門交流会を後年の資料から推測して補わない。

## 1. 取材範囲

東京ゲームショウ2010の公式開催概要は、9月16-17日をビジネスデイ、9月18-19日を一般公開日、会場を幕張メッセとしている。本巻は主催者の企画ページ、参加規定、コスプレ・ダンスナイトのページ、9月19日の開催結果を用い、告知された企画、公表規定、閉幕後に確認されたイベント全体を区別する。[^tgs-overview][^tgs-cosplay][^tgs-rules][^tgs-night][^tgs-report]

東京ゲームショウは総合ゲーム展示会であり、animegao kigurumi の専門イベントではない。規定は「大きな着ぐるみ」を直接挙げ、英語版は “large size full-body suits” と訳すが、animegao 参加者、人数、具体的な来場結果を特定しない。本巻は**公共展示会における大型着ぐるみの規則境界と、企画された周辺 cosplay 基盤**だけを記録し、一般 cosplay 企画や総来場者数を kigurumi 来場証拠へ読み替えない。

## 2. 検証可能な節点

### 9月18-19日：TGS が一連の cosplay 企画を新設

一般公開日のページは、3・4ホール間の「やすらぎのモール」を cosplay エリアとし、コスプレグランプリ、海外 cosplayer の招待、コスウォール撮影、パフォーマンス枠、コスプレ・ダンスナイトを告知した。9月19日の開催結果は、これらを「今年から新たに企画したコスプレイベント」と明記している。したがって新企画は、後年の回想や二次情報ではなく、閉幕した TGS 2010 全体に属することを確認できる。[^tgs-cosplay][^tgs-report]

開催結果は各企画の参加者を個別に示さず、animegao や大型着ぐるみの実参加も説明しない。安定して記録できる節点は、主催者が一連の cosplay 企画を新設・実施したことまでであり、特定群の参加ではない。

### 9月18-19日：7ホールの更衣、クローク、早朝利用が一つの参加動線を構成

主催者は cosplay 更衣室を7ホールに置き、海浜幕張駅の始発から8:00まで早朝開室する予定とした。8:00前に更衣を終えた参加者は一般待機列の最後尾へ戻る運用だった。500円、指定更衣、衣装確認は[2004年巻](../2004/index.md)まで遡り、裁縫道具貸出は[2009年巻](../2009/index.md)に残す。本巻では共同手順を繰り返さない。[^tgs-cosplay][^tgs-rules]

大型着ぐるみ、撮影同意、壁背景、非営利利用の境界は2004年にすでに公表されていた。2010年アーカイブに実質変化は見られず、継続としてのみ扱う。[^tgs-rules]

### 9月18日：ダンスナイト参加者の更衣室利用を21:00まで延長

コスプレ・ダンスナイトは18:00-20:00、8ホールのイベントステージで行うと掲載された。保存ページは終了済みと表示し、当日に限りダンスナイト参加者だけが7ホール更衣室を21:00まで利用できると定めている。[^tgs-night]

ここで確認できるのは一般 cosplay 夜間企画のための設備延長である。animegao または kigurumi の演目は示されず、該当参加者の来場を確定できない。

## 4. 2009年および2011-2025年との重複排除

| 継続テーマ | 2010年に残す内容 | 後年の扱い |
| --- | --- | --- |
| TGS cosplay 企画 | 開催結果が「今年から新たに企画」と確認する一連の企画 | 2011年の一般 cosplay 夜間企画を新しい kigurumi 節点にしない |
| 更衣とクローク | 7ホール、500円、早朝開室、ダンスナイト参加者の21:00までの利用 | 2011年は2ホールへの移動、2012年は7ホールへの復帰と新しい空間境界を残す |
| 大型着ぐるみ規定 | 2004年境界の継続で、新規節点ではない | 共通規定は2004年に残し、後年は実質変化だけを扱う |
| 撮影と伝播 | 2004年の同意、壁背景、非営利境界を継続 | 後年は場所または伝播規則の実質的変化だけを残す |

## 5. 年度結論

2010年に安定して記録できるのは、東京ゲームショウの新しい一体的 cosplay 企画、7ホールの早朝更衣、ダンスナイト参加者の21:00までの延長である。大型着ぐるみ、更衣・クローク、撮影同意、壁背景、非営利境界の基礎は2004年に残し、2009年は後の運用追加だけを扱う。開催結果は新企画を含む TGS 2010 の閉幕を確認するが、animegao または大型着ぐるみ参加者の来場は証明しない。
