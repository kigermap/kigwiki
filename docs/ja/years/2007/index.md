# 2007年 Kigurumi 編年史

> 本巻は当年の出来事、作品、公開資料を記録します。告知、開催記録、資料の発表を区別します。

## 検証可能な節点

### 9月22-23日：公開 cosplay 運用が継続

2007年規定は、大型着ぐるみ、50センチの小道具上限、クローク込み500円の指定更衣室、出口の衣装確認、限定撮影区域、被写体同意、個人サイト掲載許可を引き続き掲げる。[^tgs-rules] 2004年規定と項目ごとに比較しても、新しい制度節点となる実質変化は確認できない。共同条文は [2004年巻](../2004/index.md) に残し、本ページは継続のみ記録する。

### 9月23日：公式告知が閉幕を確認

主催者サイトは東京ゲームショウ2007が9月23日に閉幕したと記す。[^tgs-news] 展示会全体の実施は確認できるが、cosplay、大型着ぐるみ、animegao 別の参加・運用結果は示さない。
