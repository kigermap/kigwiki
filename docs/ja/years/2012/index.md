# 2012年 Kigurumi 編年史

> 2013-2025年は整理済みである。「完了年を再収録せず、1回につき過去1年だけ進める」という方針に従い、本巻は2012年のみを扱う。確認できる一次資料は東京ゲームショウ2012の主催者アーカイブに集中している。日時、場所、結果を確かめられない専門交流会を、後年の資料から推測して補わない。

## 1. 資料と証拠の境界

東京ゲームショウ2012の公式開催概要は、9月20-21日をビジネスデイ、9月22-23日を一般公開日、会場を幕張メッセとしている。本巻はさらに、主催者が保存する日本語・英語のコスプレ参加規定から、衣装、更衣、クローク、移動、撮影、画像利用について当年公表された条件を確認する。[^tgs-overview][^tgs-rules]

東京ゲームショウは総合ゲーム展示会であり、animegao kigurumi の専門イベントではない。日本語規定は「大きな着ぐるみ」を直接挙げ、英語版は “large size full-body suits” と訳しているが、特定の animegao 参加者、専門交流会、参加人数は示していない。本巻が記録するのは**公共展示会が大型着ぐるみと隣接するコスプレ基盤をどのように管理したか**であり、規定の存在を参加実績には置き換えない。

## 2. 検証できる節点

### 9月22-23日：大型着ぐるみが公共展示会の衣装境界に入る

一般公開日の参加規定は、大きな着ぐるみ、ハリボテ、床に引きずる長さのスカートやマントを「周囲の迷惑になるコスチューム」に含める。長いスカートやマントは撮影時のみ広げられ、移動時には折りたたむよう求められた。[^tgs-rules]

この記載は animegao の来場を証明せず、すべての kigurumi が同じ寸法上の危険を持つことも意味しない。確認できる範囲は、2012年までに主催者が着ぐるみという名称を用い、大型全身衣装が公共動線へ与える影響を扱っていたことである。

### 9月22-23日：7ホールの更衣、クローク、補修支援が一つの参加動線になる

指定更衣室は7ホール南側に置かれ、使用料500円にクローク代が含まれた。トイレなど指定場所以外での着替え、更衣室内の飲食、休憩、撮影は禁止され、盗撮カメラなどの不審物は直ちにスタッフへ知らせるよう求められた。出口では衣装確認があり、規定違反の小道具は預けられる場合があった。参加者は16時までに更衣室へ戻り、衣装を着たまま来場・退場することも禁止された。[^tgs-rules]

更衣室は海浜幕張駅の始発時刻から8時まで早朝開放する予定とされ、裁縫道具の貸し出しも案内された。アーカイブが証明するのは費用、設備、手順が公表されたことまでであり、閉幕後報告ではないため、各サービスの利用数や animegao 参加を単独では確認できない。

### 9月22-23日：指定撮影区域と画像利用の境界が同時に示される

撮影可能場所は、3・4ホール間の「やすらぎのモール」の一部と、会場南側・海側屋外のコスプレエリアに限られた。撮影前には被写体の許可を取り、無関係な人が写らないようにする必要があった。動画撮影、営利目的の撮影、会場写真の出版物への投稿や売買は禁止され、個人サイトへの掲載にも関係者の許可が必要だった。[^tgs-rules]

2013年の公式規定は、更衣室が「昨年の7ホール」から9ホールへ移動し、それまで使用した「やすらぎのモール」が撮影に使えなくなったことを明記する。[^tgs-2013] したがって本巻は、**移動前の空間、料金、画像利用の基準**を2012年固有の記録として残し、2013年と共通する同意原則は重ねて拡張しない。

## 4. 2013-2025年との重複排除

| 継続テーマ | 2012年に残す内容 | 後年の扱い |
| --- | --- | --- |
| 公共展示会の着ぐるみ | 現在検証できるアーカイブではより早い「大きな着ぐるみ / large size full-body suits」規定 | 2013年は9ホール拡張後の空間運用を残し、同文を反復しない |
| 更衣とクローク | 7ホール南側、クローク込み500円、16時帰着、裁縫道具貸出 | 2013年は9ホール移動とホール間移動条件を残す |
| 撮影と流通 | やすらぎのモール、海側屋外区域、動画・営利撮影・出版利用制限 | 2013年は撮影区域再編、後年は新しい媒体や異なる規定のみを残す |
| animegao 専門活動 | 十分な一次資料なし | 後年の活動から2012年へ逆算しない |

## 5. 年度結論

2012年に安定して記録できるのは animegao 専門イベント一覧ではなく、東京ゲームショウの移動前にあった公共参加の基準である。大型着ぐるみは動線規定に含まれ、7ホール南側では有料の更衣・クローク、早朝更衣、補修支援が案内され、撮影は指定区域に限られた。動画、営利撮影、出版利用、個人サイト掲載には別々の制限があった。2013年公式ページの7ホールからの移動と旧撮影区域廃止の記載によって、この2012年基準は年をまたいで照合できる。一方、具体的参加者、専門交流会、設備利用数、開催結果は未確認のまま残す。
