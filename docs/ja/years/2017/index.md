# 2017年 Kigurumi 編年史

> 2016年と2018-2025年には独立した年次ページがある。本重複整理では、2017年に追加された AnimeJapan の会場設備と一件の自主調査だけを残し、2016年に記録した着ぐるみの基礎的なエリア・撮影・更衣規則は反復しない。

## 1. 資料の境界

本巻は二種類の記録を用いる。AnimeJapan の公式ページは日付、会場、当年規則を確認できる。サイト内に保存する『着ぐるみ国勢調査結果報告書』は、調査期間、回答数、設問、著者自身が述べた限界を確認できる。後者は無作為抽出でも査読研究でもないため、比率を kigurumi コミュニティ全体へ一般化できない。

年次ページでは73ページの本文と205点の図を複製せず、編年上の意味だけを記し、[調査報告の完全資料ページ](../../sources/survey-reports/kigurumi-census-2017/index.md)へ接続する。

## 2. 確認できる節点

### 3月25-26日：AnimeJapan 2017 が公共 cosplay 空間と更衣選択を拡張

AnimeJapan 2017 のパブリックデイは3月25-26日に東京ビッグサイト東1-7ホールで開催され、イベント全体では2016年より1ホール多く使用した。Cosplayers World は東7ホールへ移動し、自身のスペース拡大を明記した。通常の登録、共用更衣室、クローク、撮影エリアに加え、1テーブル最大3名で使う別料金・女性専用のプレミアム更衣室を初めて導入した。[^aj-outline][^aj-cosplay]

視界・移動を制限する衣装の cosplay エリア限定、撮影同意、更衣室のプライバシーという基礎規則は2016年巻に記録済みであり、2017年は初出ではなく継続である。[^aj-cosplay] 本年固有の節点は、収容力の拡張と標準更衣室以外の女性専用プレミアム選択である。これは総合イベントの基盤であり、animegao 専門イベントの証拠ではない。

### 10月4日から約一週間：自主的な「国勢調査」が数量的スナップショットを残す

くっしー（@kussy_tessy）が実施した「着ぐるみ国勢調査」は221件の回答を得た。冒頭の同意項目で同意しなかった1件を除き、有効回答は220件である。調査は著者周辺の Twitter ネットワークを通じて広がった。前書きは母集団の偏り、設問視角、非中立性を明記しているため、本サイトはこれを**境界の明確なコミュニティ自己記録**として扱い、人口調査や学術的結論とはみなさない。[^census]

報告は参加形態、活動年数、面と衣装、制作元、撮影、交流、自己理解、親密な話題を含む。年次概観に安全に使える限定指標では、参加形態の有効回答217件のうち53%が「イベントや off 会で着る」、15%が「主に一人で着る」と回答した。活動年数は有効回答216件、平均5.9年で、未活動者を除いても過半数は5年以下だった。[^census] 比率はこの標本だけを記述する。

## 3. 分野判断

| 分野 | 2017年に確認できる内容 | 編集判断 |
| --- | --- | --- |
| 編年史 | AnimeJapan パブリックデイ、10月の自主調査 | 年次主軸に収録 |
| 日常 / 雑談 | 参加形態とコミュニティの自己記述 | 標本のスナップショットに限定 |
| 工房 / 手作業 | 報告内の面、肌タイ、供給元 | 完全報告へ接続し、教程化しない |
| 百科 / 啓発 | 220件の有効回答が用語と実践を保存 | 資料史として収録 |
| 礼儀 | 基礎規則を継続し、別料金の女性専用プレミアム更衣室を追加 | 2017年の設備変更だけを収録 |
| 学術 | 2017年の直接関連査読成果は未確認 | 個人調査を学術研究と誤記しない |

既存の「調査報告」区分が完全資料を収めているため、重複する独立区分は作らない。一件の限定的調査だけでは独立学術欄を設ける根拠にもならない。

## 4. 2016年および2018-2025年との重複整理

| 継続主題 | 2017年に残す内容 | 後年の扱い |
| --- | --- | --- |
| AnimeJapan | 東7ホールへの拡張と初の別料金女性専用プレミアム更衣室 | 基礎エリア・撮影・更衣規則は2016年、2018年はパレードのアテンド要件を扱う |
| コミュニティ研究 | 個人実施、Twitter 周辺標本の2017年調査 | 2018年は慶應の学位研究であり、資料性質が異なる |
| 公式 IP / 専門イベント | 本調査では十分な一次資料なし | 2019-2025年の確認済み内容を遡及しない |

## 5. 年次結論

2017年の確実な記録は密集したイベント一覧ではなく、二つの増分である。大規模公共会場は cosplay の収容力と更衣選択を拡張し、コミュニティは比較的大規模な数量的自己記録を残した。基礎規則は2016年巻が担い、2017年の便宜標本もコミュニティ全体を代表しない。
