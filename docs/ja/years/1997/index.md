# 1997年 Kigurumi 編年史

> 1998-2025年の巻は整理済みです。「完了年を繰り返さず、1回につき過去年を1年だけ整理する」という方針に従い、本巻では1997年のみを追加します。東京ゲームショウ公式30周年史は、1997年春・秋の開催日、総来場者数、年1回から春秋開催への移行を確認できますが、1997年の写真・企画・統計を kigurumi / animegao と明記していません。本巻は後年の事実を遡及させず、同時期の公開背景と証拠境界だけを記録します。

## 1. 取材範囲

公式史は第2回を1997年春とし、4月4-6日、来場者121,172人、第1回の盛況を受けて春秋の年2回開催になったと説明しています。第3回は1997年秋、9月5-7日、来場者140,630人です。[^tgs-history] これらの項目から、両イベントと開催頻度の変化は確認できます。

同ページには写真とポスターがありますが、本文は各画像の人物、衣装分類、kigurumi / animegao の別を示さず、画像の代替テキストも空です。本アーカイブへの明示的な再利用許諾もありません。本巻は第一方資料へリンクするだけとし、説明のない画像を専門実践の記録と判定せず、素材も転載しません。

[1998年巻](../1998/index.md)以後には、隣接するイベント背景、2003年の専門サイト開始点、2004年の公開規則をすでに収録しています。本巻ではそれらを1997年へ移しません。該当する第一方の旧サイトは今回の再確認時に応答しませんでしたが、これはアクセス上の制約であり、1997年の別の実践、個人サイト、イベントの有無を証明しません。

## 2. 検証可能な節点

### 4月4-6日：TGS 1997春の完了記録

公式30周年史は第2回を「1997年・春」とし、4月4-6日、121,172人を記録し、第1回の盛況を受けて春秋開催になったと説明しています。[^tgs-history] これはイベント全体と運営頻度の背景であり、kigurumi の参加、制作、マナー規則の記録ではありません。

### 9月5-7日：TGS 1997秋の完了記録

同じ公式ページは第3回を「1997年・秋」とし、9月5-7日、140,630人を記録しています。[^tgs-history] 総来場者数から、特定の装演分類の規模、初出、実参加を判断することはできません。

### 後年の専門出版と規則を遡及させない

[2003年巻](../2003/index.md)には現在整理済みの専門ウェブ出版開始点を、[2004年巻](../2004/index.md)には現在直接確認できる最古の大型着ぐるみ公開規則を残します。どちらも1997年へ移さず、公式史の説明のない画像から人物の属性を推定しません。

## 5. 年次結論

1997年に安定して記録できるのは、東京ゲームショウ春秋2回の実日程、主催者回顧の来場者数、年2回開催への移行、およびそれらが kigurumi / animegao の専門規則や参加を証明しないという境界です。後年の専門出版と公開規則は元の年に残します。次の未整理年は1996年です。
