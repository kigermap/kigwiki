# 2001年 Kigurumi 編年史

> 2002-2025年は整理済みである。「完了年を繰り返さず、1回につき1年だけ遡る」という方針に従い、本巻は2001年だけを追加する。東京ゲームショウ公式30周年ページからは2001年春・秋の開催日と来場者数を確認できるが、写真、企画、統計項目のいずれも kigurumi / animegao として説明されていない。本巻は2002-2004年の資料を遡及させず、隣接する公開イベントの背景と証拠境界を記録する。

## 1. 取材境界

東京ゲームショウ公式史は、2001年春を第10回、開催日を3月30日-4月1日、来場者数を118,080人とする。秋は第11回、10月12-14日、129,626人である。春の項目には Bill Gates 氏の基調講演も記録されている。[^tgs-history] これらは主催者の回顧記録であり、予定表より直接的にイベントの実施を確認できる。

同ページは各回の写真とポスターも掲載するが、人物、衣装分類、kigurumi / animegao を個別に特定するキャプションはない。来場者統計と説明のない写真だけでは、専門規則、コミュニティの参加、特定の演者を立証できない。画像の再利用を認める明示的なライセンスも見当たらないため、本巻は出典へのリンクに留め、画像を複製しない。

Inside Doll の一次ページは、同専門サイトの開始を2003年4月に置く。更新履歴も正式公開を2003年とするが、具体的な日付はトップページと食い違う。[^inside-main][^inside-news] これは同サイトを2001年へ前倒しできないことを示すだけであり、2001年に他の kigurumi 実践、個人ページ、イベントが存在しなかったことの証明ではない。

## 2. 検証可能な記録

### 3月30日-4月1日：TGS 2001春の実施記録

公式30周年回顧は第10回を「2001年・春」とし、3月30日-4月1日、来場者118,080人、Bill Gates 氏の基調講演を記録する。[^tgs-history] これは同時期の公開イベント背景であり、kigurumi 参加記録ではない。

### 10月12-14日：TGS 2001秋の実施記録

同じ公式ページは第11回を「2001年・秋」とし、10月12-14日、来場者129,626人を記録する。[^tgs-history] kigurumi、animegao、大きな着ぐるみ、更衣、クローク、撮影に関する直接引用可能な規則は示されていないため、総来場者数を関連参加者数へ読み替えない。

### 後年の専門サイトと規則を前倒ししない

[2003年巻](../2003/index.md)には Inside Doll の公開開始を、[2004年巻](../2004/index.md)には直接検証できる最初期の大きな着ぐるみ公開規則を残す。本巻は両者を2001年へ移さず、公式史写真の未説明の被写体を特定の装演分類へ割り当てない。

## 3. 分野判定

| 分野 | 2001年に検証可能な内容 | 編集判断 |
| --- | --- | --- |
| 編年 | TGS 春・秋の実施日と来場者数 | 隣接する公開背景としてのみ収録 |
| 日常 / 雑談 | 同年の専門記録を確認できず | 後年の回想や現在の検索結果で補わない |
| 工房 / 手工 | 同年の制作工程・材料記録を確認できず | 収録しない |
| 百科 / 啓発 | イベント実施記録は kigurumi 参加の証拠ではない | 証拠注記として収録 |
| 礼儀 / 安全 | 同年の専門的な kigurumi / cosplay 規則を確認できず | 2004年から推定しない |
| 学術 | 2001年の直接関連する検証可能な研究を確認できず | 収録しない |

年次編年と証拠注記で十分であり、隣接イベント2件のために独立したイベント、工房、人物、学術分野は設けない。

## 4. 2002-2025年との重複排除

| 継続主題 | 2001年巻に残す内容 | 後年での扱い |
| --- | --- | --- |
| TGS 公開背景 | 2回の実施期間、来場者数、証拠境界 | 2002年は計画ページの境界、2004年は直接引用できる大きな着ぐるみ規則を保持 |
| 専門ネット出版 | 2003年の開始記録を前倒ししない | Inside Doll の開始は2003年だけに置く |
| 現実の参加 | マスク、演者、工房、参加人数の証拠空白を保持 | 総来場者数、無説明写真、後年規則から推定しない |
| 画像 | 明示的な再利用許可のない写真を複製せず公式史へリンク | 許可と検証可能な説明が得られた場合のみ再評価 |

## 5. 年次結論

2001年について安定して記録できるのは、東京ゲームショウ春・秋の実施日と主催者回顧による来場者数、そしてこれらが kigurumi / animegao の専門規則や参加を立証しないという境界である。2003年の専門サイトと2004年の公開規則は元の年に残す。次の未整理年は2000年である。
