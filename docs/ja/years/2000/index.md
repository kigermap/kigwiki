# 2000年 Kigurumi 編年史

> 2001-2025年は整理済みである。「完了年を重複せず、一回につき過去一年だけ進める」という方針に従い、本巻は2000年だけを追加する。東京ゲームショウ公式30周年ページは、2000年春・秋の開催日、来場者数、秋の累計来場者100万人到達を確認できるが、写真、企画、統計のいずれも kigurumi / animegao として識別していない。本巻は後年資料で補完せず、同時期の公共背景と証拠境界を記録する。

## 1. 取材境界

東京ゲームショウ公式沿革は、2000年春を第8回、3月31日-4月2日、来場者131,708人と記録する。第9回の秋は9月22-24日、137,400人で、累計来場者100万人到達と記念セレモニーも記されている。[^tgs-history] 主催者による回顧記録なので、展示会自体が実施されたことを確認できる。

同ページには両回の写真とポスターがあるが、人物、衣装分類、kigurumi / animegao 参加を画像ごとに説明していない。来場者数、累計節目、説明のない写真だけでは、専門規定、社群参加、特定演者の証拠にならない。画像再利用を許す明示的な条件もないため、本巻は出典へリンクするだけで転載しない。

Inside Doll の一次ホームページは同専門サイトの開始を2003年4月とし、更新履歴も正式公開を2003年に置くが、具体日は互いに食い違う。[^inside-main][^inside-news] これは同サイトを2000年へ遡らせないための境界であり、当年に他の kigurumi 実践、個人ページ、催事が存在しなかったことの証明ではない。

## 2. 検証可能な節点

### 3月31日-4月2日：TGS 2000春の実施記録

公式30周年回顧は第8回を「2000年・春」とし、3月31日-4月2日、来場者131,708人を記録する。[^tgs-history] これは同時期の公共展示会背景であり、kigurumi 参加記録ではない。

### 9月22-24日：TGS 2000秋の実施記録

同ページは第9回を「2000年・秋」とし、9月22-24日、137,400人、累計来場者100万人到達と記念セレモニーを記録する。[^tgs-history] この節目は展示会全体を説明するもので、装演分類の規模、初出、完了状態ではない。

### 後年の専門サイトと規定を前倒ししない

[2003年巻](../2003/index.md)は Inside Doll の公開起点を保持し、[2004年巻](../2004/index.md)は現在直接検証できる最古の大型着ぐるみ公共規定を保持する。本巻は両者を2000年へ移さず、公式沿革写真の説明されていない対象を特定の装演分類として識別しない。

## 3. 分野判定

| 分野 | 2000年に検証できる内容 | 編集判断 |
| --- | --- | --- |
| 編年史 | TGS春・秋の実施日、来場者数、秋の累計節目 | 隣接する公共背景としてのみ収録 |
| 日常 / 雑談 | 同年の専門記録を取得できず | 後年の回想や現在の検索結果で補わない |
| 工房 / 手作り | 同年の制作工程・材料記録を取得できず | 収録しない |
| 百科 / 解説 | 展示会の完了と累計来場者数は kigurumi 参加の証拠ではない | 証拠説明として収録 |
| 礼儀 / 安全 | 同年の kigurumi / cosplay 専門規定を取得できず | 後年規定から推定しない |
| 学術 | 2000年の直接関連する新規検証可能研究を確認できず | 収録しない |

既存の年度編年と証拠説明で十分であり、二つの隣接公共展示会記録のために独立したイベント、工房、人物、学術区分を新設しない。

## 4. 2001-2025年との重複排除

| 継続テーマ | 2000年巻に残す内容 | 後年の扱い |
| --- | --- | --- |
| TGS公共背景 | 両回の実施日、来場者数、累計節目、証拠境界 | 2001年は次の二回の実施記録、2004年は直接引用できる大型着ぐるみ規定を保持 |
| 専門ネット出版 | 2003年の起点を前倒ししない | Inside Doll の起点は2003年だけに残す |
| 現実の参加 | 同年のマスク、演者、工房、参加人数に関する証拠空白 | 展示会総来場者、説明のない写真、後年規定から推定しない |
| 画像 | 再利用許可が明確でない公式写真を複製せず沿革ページへリンク | 許可と検証可能な説明を取得した場合だけ再評価 |

## 5. 年度結論

2000年に安定して記録できるのは、東京ゲームショウ春・秋の実施日、主催者回顧の来場者数、秋の累計来場節目と、それらが kigurumi / animegao 専門規定や参加を証明しないという境界である。2003年の専門サイトと2004年の公共規定は出典年に残す。次の未整理年は1999年である。
