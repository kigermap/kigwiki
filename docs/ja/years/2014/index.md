# 2014年 Kigurumi 編年史

> 2015-2025年は整理済みである。「整理済みの年を重複せず、一回につき過去一年だけ進める」という方針に従い、本巻は2014年のみを扱う。検証可能な一次資料は AnimeJapan 2014 の主催者による開催後報告に集中している。日付、場所、結果を確認できない専門集会は推測で補わない。

## 1. 資料の境界

本巻は AnimeJapan が保存する2014年の開催報告を用いる。そこから開催日、会場、公式キャラクター着ぐるみの交流、Cosplayers World の屋内外撮影エリアと衣装レンタルが実際に運用されたことを確認できる。[^aj-report]

AnimeJapan は総合アニメイベントであり、animegao kigurumi の専門イベントではない。報告はドラえもん、ケロロ軍曹などの登場を明確に「着ぐるみ」と記す一方、Cosplayers World の一般参加者を animegao と特定していない。そこで本巻は、**公式キャラクター着ぐるみ**と、**全頭型衣装も利用しうる公共 cosplay 基盤**を分ける。一般 cosplay 写真や全体来場者数を animegao 参加の証拠にはしない。

## 2. 検証済みノード

### 3月22-23日：Family Park でキャラクター着ぐるみの公開交流を実施

AnimeJapan 2014 は3月22-23日に東京ビッグサイト東1-6ホールで開催された。主催者報告によると、Family Park のふれあいステージにはドラえもん、ケロロ軍曹などのキャラクター着ぐるみが順番に登場した。家族だけでなく、成人のアニメファンやカップルも記念撮影と握手に参加した。隣接する撮影コーナーには、クレヨンしんちゃん、あらいぐまラスカルなどのキャラクターぬいぐるみも展示された。[^aj-report]

これは公式キャラクター / mascot の文脈であり、animegao 参加者のイベントではない。編年上確認できるのは、2014年の総合アニメイベントでキャラクター着ぐるみが撮影と握手を中心とする公開プログラムとして組織されていたことである。

### 3月22-23日：Cosplayers World の屋内外撮影基盤が実運用

同じ開催後報告は、Cosplayers World が屋内と屋外の撮影エリアを運用したことを確認している。屋内では『艦隊これくしょん』『進撃の巨人』『魔法少女まどか☆マギカ』などと連動するセットと背景パネルを提供し、屋外にはアニメ、ゲーム、漫画の cosplayer と撮影者が集まり、海外参加者も記録された。ACOS と COSPA の協力により、1時間1,000円の衣装レンタルも行われ、初めて cosplay を行う来場者への入口となった。[^aj-report]

これらは animegao kigurumi の存在や人数を証明しない。本巻では、2015年報告が更衣室と屋外エリアを前年より拡張したと述べる前段の基線としてのみ残す。拡張、登録・保管料金、移動管理、撮影規則は2015年巻に置く。

## 5. 年度結論

2014年に確認できるのは animegao 専門イベント一覧ではなく、二つの異なる公共実践である。Family Park では公式キャラクター着ぐるみが撮影と握手を担い、Cosplayers World では屋内外撮影エリア、作品セット、衣装レンタルが公共 cosplay の基盤を形成した。両者は分けて記述しなければならない。主催者報告はプログラムの実施を証明するが、animegao 参加者、専門集会、コミュニティ規模までは証明しない。その空白は残す。
