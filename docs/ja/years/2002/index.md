# 2002年 Kigurumi 編年史

> 2003-2025年は整理済みである。「完了年を重複せず、一回につき過去一年だけ進める」という方針に従い、本巻は2002年だけを追加する。現存する一次ページは、後年に大型着ぐるみ規定を公開する隣接展示会の2002年日程と会場を確認できるが、当年の kigurumi / animegao 専門規定や実参加は証明しない。本巻は2003年や2004年の資料で穴を埋めず、この証拠境界を記録する。

## 1. 調査範囲

東京ゲームショウ2002の日経BP / CESA一次アーカイブは、9月20日をビジネスデイ、9月21-22日を一般公開日、会場を日本コンベンションセンター（幕張メッセ）とし、15万人を「来場予定者数」と明記する。[^tgs-outline] これらは同時期の公共展示会という背景だけを示す。予定人数は最終結果ではなく、予定日程だけで全企画の実施も証明できない。

今回閲覧できた2002年アーカイブは Business Person Side のトップと開催概要であり、kigurumi、animegao、大型着ぐるみ、更衣、クローク、撮影の直接引用可能な規定を含まない。当時の公式サイトへのルートリンクは現在では後年のサイトを指し、現在ページから2002年の来場者規定を復元できない。Inside Doll の一次ページは自サイトの開始を2003年4月に置く。これは前倒しを制限するが、2002年に別の専門サイトや活動がなかったことを証明しない。[^inside-main][^inside-news]

## 2. 検証可能な記録

### 9月20-22日：隣接する公共展示会が日程と会場を公開

公式概要は9月20日をプレス・招待者などに限るビジネスデイ、9月21-22日を10:00-17:00の一般公開日とし、幕張メッセ、主催 CESA、共催の日経BPを記す。[^tgs-outline] これは検証可能な年度背景であり、kigurumi の参加記録ではない。

### 同年資料から引用可能な kigurumi 規定は形成できない

[2004年巻](../2004/index.md)では「大きな着ぐるみ」、指定更衣、クローク、衣装確認、撮影同意を直接引用できる。対して閲覧可能な2002年ページは開催概要とビジネス情報だけである。資料の沈黙は関連衣装が現場になかった証明にならず、2004年規定を2002年の既存制度とみなす根拠にもならない。

### 2003年専門サイトの開始を前倒ししない

Inside Doll のメインページは「2003/04/23 start」、更新履歴は2003年4月5日を正式公開とする。日付は矛盾するが、どちらも公開起点を2003年に置く。[^inside-main][^inside-news] したがって専門ネット出版の記録は [2003年巻](../2003/index.md)に残し、2002年へ移さない。

## 3. 分野判断

| 分野 | 2002年に検証できる内容 | 編集判断 |
| --- | --- | --- |
| 編年史 | TGS 2002の予定日程、一般公開日、会場 | 隣接する公共背景としてのみ収録 |
| 日常 / 雑談 | 同年の専門記録を確認できず | 後年サイトの更新で補わない |
| 工房 / 手作り | 同年の現実の制作工程を確認できず | 収録しない |
| 百科 / 啓発 | 「展示会が存在した」と「kigurumi が参加した」は別の主張 | 証拠説明に収録 |
| 礼儀 / 安全 | 同年の kigurumi / cosplay 規定を確認できず | 2004年から推定しない |
| 学術 | 2002年の直接関連研究を確認できず | 収録しない |

年次編年と証拠説明で十分であり、一件の背景ページからイベント、工房、人物、学術の独立区分は作らない。

## 4. 2003-2025年との重複排除

| 継続する主題 | 本巻に残す内容 | 後続年の扱い |
| --- | --- | --- |
| TGS の公共背景 | 予定日程、一般公開日、会場、予定人数という境界 | 2004年に直接検証できる最初の大型着ぐるみ規定を残す |
| 専門ネット出版 | 2003年開始記録を前倒ししない | Inside Doll の開始と更新リズムは2003年だけに残す |
| 現実参加 | マスク、演者、工房、人数の証拠空白 | 後年規定、創作、現行サイトから推定しない |
| 完了状態 | 予定期間を完了結果にしない | 同年の終了・実施記録が得られた場合だけ更新する |

## 5. 年度結論

2002年に安定して記録できるのは、東京ゲームショウが公表した予定日程、一般公開日、幕張会場と、これらが kigurumi / animegao 専門規定や実参加を証明しないという境界である。2003年の専門サイトと2004年の大型着ぐるみ公共規定は元の年に残す。後年資料から完全な物語を作るより、空白を公開する方が編年史として正確である。次の未整理年は2001年となる。
