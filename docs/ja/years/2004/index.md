# 2004年 Kigurumi 編年史

> 2005-2025年は整理済みである。「完成年を繰り返さず、一回につき一年前だけへ進む」という方針に従い、本巻は2004年のみを追加する。東京ゲームショウ2004の主催者資料は「大きな着ぐるみ」を直接記し、更衣、クローク、撮影の一連の規定を残している。本巻はその共通条項を現在検証できる最初の節点へ移し、2006年を起点とはしない。

## 1. 取材範囲

東京ゲームショウは総合ゲーム展示会であり、animegao kigurumi の専門イベントではない。日本語規定の「大きな着ぐるみ」は周囲の来場者の迷惑になる**大型**着ぐるみを意味し、大型ハリボテや床を引きずるスカート・マントと並ぶ。これは寸法、動線、公共安全の分類であり、animegao、美少女着ぐるみ、またはすべての仮面衣装の同義語ではない。[^tgs-rules]

規定の存在は、主催者が事前にその衣装区分を管理したことだけを示し、実来場を証明しない。終了報告の160,096人もゲーム展示会全体の総入場者数であり、cosplay、kigurumi、animegao の参加人数には換算できない。[^tgs-report]

## 2. 検証可能な節点

### 9月24-26日：日程、会場、一般公開枠

主催者トップページは9月24日をビジネスデイ、9月25-26日を一般公開日、会場を幕張メッセ、開場時間を10:00-17:00と記す。cosplayer 向けの独立した規定入口も設けられていた。[^tgs-home]

### 9月25-26日：大きな着ぐるみが公共衣装の境界に入る

規定は大きな着ぐるみ、大型ハリボテ、床を引きずるスカートやマントを、周囲の迷惑になる衣装として列挙し、苦情があれば cosplay を中止させる場合もあるとした。小道具には別に全長50センチの上限があり、危険な武器、可燃物、強い臭気、騒音を生む器材・行為を禁じた。[^tgs-rules]

これは現在整理済みの年のうち、「大きな着ぐるみ」を直接確認できる最初の公共規定である。ただし、実参加記録ではない。

### 9月25-26日：更衣、クローク、確認、撮影同意の一連の流れ

指定更衣室はクローク込み500円で、トイレなど別の場所での更衣、衣装のままの来場・外出は禁止された。更衣室内での飲食、休憩、撮影も認められず、出口ではスタッフが衣装を確認し、規定違反の小道具を預かる場合があった。[^tgs-rules]

撮影場所は3・4ホール間「やすらぎのモール」の一部に限定された。被写体の許可を取り、無関係な人が写らないよう壁を背景にする必要があった。会場写真の出版物への投稿や売買は禁止され、個人ホームページへの掲載にも事前説明と許可が必要だった。[^tgs-rules]

### 9月27日：主催者が3日間の開催完了を確認

終了報告は9月24-26日の開催と3日間合計160,096人の入場を確認する。[^tgs-report] これにより規定に対応する展示会全体の実施は確認できるが、cosplay 規定の執行結果や大きな着ぐるみ・animegao の参加者は報告されていない。

## 4. 2005-2025年との重複整理

| 継続主題 | 2004年巻に残す内容 | 後年の扱い |
| --- | --- | --- |
| 大きな着ぐるみ規定 | 現在検証できる最初の主催者文言と寸法・動線の文脈 | 2006・2007年は同文継続だけを記し、条文は反復しない |
| 更衣、クローク、確認 | クローク込み500円、指定更衣、出口確認 | 2006・2007年は継続のみ、2009年は裁縫道具と受付時限を残す |
| 撮影と流通 | 指定区域、被写体許可、壁背景、個人サイト掲載同意 | 後年は会場または流通の実質変更のみ残す |
| 実参加 | animegao・大きな着ぐるみ来場の証拠空白 | 規定や総入場者数から参加を推定しない |
| 2005年資料 | 2004年規定で翌年の空白を埋めない | 2005年は検証できる予定日程と証拠境界のみ残す |

## 5. 年次結論

2004年に安定して記録できるのは、東京ゲームショウが大きな着ぐるみ、指定更衣、クローク、衣装確認、撮影同意を公開 cosplay 手順に含め、終了報告が展示会全体の完了を確認したことである。公開資料は animegao または大きな着ぐるみの実来場を証明しない。2006年に項目ごとに繰り返された共通条項は2004年を基準とし、後年は継続または変更だけを残す。次の未整理年は2003年である。
