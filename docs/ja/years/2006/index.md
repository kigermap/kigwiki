# 2006年 Kigurumi 編年史

> 2004年巻の追加後に本頁を再校勘した。東京ゲームショウ2006の大きな着ぐるみ、更衣、クローク、衣装確認、撮影条項は、主催者の2004年規定と項目ごとに一致するため再展開しない。本巻は2006年固有の日程、会場、閉幕確認と、規定が継続していたという結論だけを残す。

## 1. 取材範囲

公式概要は9月22日をビジネスデイ、9月23-24日を一般公開日、会場を幕張メッセと記す。主催者トップページには9月24日に東京ゲームショウ2006が閉幕したという記録が残る。[^tgs-overview][^tgs-home]

これは総合ゲーム展示会であり、animegao kigurumi の専門イベントではない。「大きな着ぐるみ」は寸法、動線、公共安全の分類である。規定の継続、出展者キャラクター、総来場者は animegao または大きな着ぐるみの実来場を証明しない。

## 2. 検証可能な節点

### 9月22-24日：当年の日程と幕張会場

公式概要は9月22日のビジネスデイ、9月23-24日の一般公開日、三日とも10:00-17:00、会場は幕張メッセと確認する。[^tgs-overview] これは2006年固有の編年情報である。

### 9月23-24日：2004年公共規定の項目ごとの継続

2006年の cosplayer 規定は、大きな着ぐるみ、小道具安全、指定更衣、クローク、出口の衣装確認、限定撮影区域、被写体許可、個人ホームページ掲載同意を引き続き扱う。[^tgs-rules] 2004年規定との項目別比較では、新しい制度節点とする実質変更を確認できない。完全な公共基準は[2004年巻](../2004/index.md)に残し、本頁は継続だけを記録する。[^tgs-2004-rules]

規定は具体的な animegao 参加者、人数、演目、執行結果を示さない。

### 9月24日：主催者が展示会全体の閉幕を確認

主催者は東京ゲームショウ2006が9月24日に閉幕したと記し、来場者へ謝意を示した。[^tgs-home] 展示会全体の実施は確認できるが、規定対象の衣装が実際に現れた証拠にはならない。

## 5. 年次結論

2006年に安定して記録できるのは、東京ゲームショウの当年日程、幕張会場、閉幕確認と、2004年公共 cosplay 規定が目に見える実質変更なく継続したことである。共同条文は反復せず、公開資料は animegao または大きな着ぐるみの実来場を引き続き証明しない。
