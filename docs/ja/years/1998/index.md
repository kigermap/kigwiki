# 1998年 Kigurumi 編年史

> 本巻は当年の出来事、作品、公開資料を記録します。告知、開催記録、資料の発表を区別します。

## 検証可能な節目

### 3月20-22日：TGS 1998 春の完了記録

公式回顧は第4回を「1998年・春」とし、3月20-22日、147,913人、入場先頭待ちグループへの記念品を記録する。[^tgs-history] これは展示会全体の入場運用背景であり、kigurumi 参加や礼儀規定の記録ではない。

### 10月9-11日：TGS 1998 秋の完了記録

同じページは第5回を「1998年・秋」とし、10月9-11日、156,455人を記録する。[^tgs-history] 総来場者数は、装演分類の規模、初出、実参加を示さない。

### 後年の専門サイトと規定を前倒ししない

[2003年巻](../2003/index.md)に Inside Doll の公開開始を残し、[2004年巻](../2004/index.md)に現在最初に直接検証できる大型着ぐるみ公共規定を残す。どちらも1998年へ移さず、公式史画像の未説明人物を特定分類へ割り当てない。
