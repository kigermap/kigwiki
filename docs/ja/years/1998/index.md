# 1998年 Kigurumi 編年史

> 1999-2025年は整理済みである。「完了年を繰り返さず、1回につき1年だけ遡る」という規則に従い、本巻は1998年だけを追加する。東京ゲームショウ30周年公式史は1998年春・秋の開催日、来場者数、春の入場待機列への記念品を確認できるが、1998年項目の写真、企画、統計を kigurumi / animegao としていない。本巻は後年から補完せず、同時期の公共背景と証拠境界を記録する。

## 1. 取材範囲

公式史は第4回を1998年春、3月20-22日、来場者147,913人とし、入場先頭待ちグループへの記念品を記す。第5回の秋は10月9-11日、来場者156,455人である。[^tgs-history] この記載により、両開催と春の待機列対応が実施済みだったことを確認できる。

同じページには写真とポスターがあるが、1998年項目は人物、衣装分類、kigurumi / animegao の属性を画像ごとに説明していない。また、本サイトへの明確な再利用許諾もない。本巻は一次ページへリンクするだけとし、説明のない画像を専門実践へ割り当てず、素材も転載しない。

Inside Doll の一次ホームページと更新履歴はいずれも専門サイトの公開開始を2003年に置くが、具体日には矛盾がある。[^inside-main][^inside-news] これは同サイトを1998年へ前倒しできないことを示すだけで、同年に別の実践、個人サイト、活動がなかったことを証明しない。

## 2. 検証可能な節目

### 3月20-22日：TGS 1998 春の完了記録

公式回顧は第4回を「1998年・春」とし、3月20-22日、147,913人、入場先頭待ちグループへの記念品を記録する。[^tgs-history] これは展示会全体の入場運用背景であり、kigurumi 参加や礼儀規定の記録ではない。

### 10月9-11日：TGS 1998 秋の完了記録

同じページは第5回を「1998年・秋」とし、10月9-11日、156,455人を記録する。[^tgs-history] 総来場者数は、装演分類の規模、初出、実参加を示さない。

### 後年の専門サイトと規定を前倒ししない

[2003年巻](../2003/index.md)に Inside Doll の公開開始を残し、[2004年巻](../2004/index.md)に現在最初に直接検証できる大型着ぐるみ公共規定を残す。どちらも1998年へ移さず、公式史画像の未説明人物を特定分類へ割り当てない。

年度編年と証拠説明で十分であり、二つの隣接公共イベント記録のために独立したイベント、工房、人物、学術区分は作らない。

## 4. 1999-2025年との重複排除

| 継続テーマ | 1998年に残す内容 | 後続年での扱い |
| --- | --- | --- |
| TGS 公共背景 | 両開催の実施日、総来場者数、春の待機列記念品と証拠境界 | 1999年は次年の両開催と春の舞台企画、2004年は直接引用できる大型着ぐるみ規定を保持 |
| 専門ネット出版 | 2003年の開始記録を前倒ししない | Inside Doll の開始点は2003年だけに置く |
| 現実参加 | 面、演者、工房、参加人数の証拠空白を保持 | 展示会総人数、未説明画像、後年規定から推定しない |
| 画像 | 再利用許可のない写真を複製せず公式史へリンク | 許諾と検証可能な説明を得てから再評価 |

## 5. 年度結論

1998年に安定して記録できるのは、東京ゲームショウ春・秋の実施日、主催者回顧の来場者数、春の待機列記念品と、それらが kigurumi / animegao 専門規定や参加を証明しないという境界である。2003年の専門サイトと2004年の公共規定は出典年に残す。次の未整理年は1997年である。
