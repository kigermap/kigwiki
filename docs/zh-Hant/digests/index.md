## 工作流程

本站採用「月度採集 → 來源複核 → 年度歸檔」：

1. 同一自然月只維護一頁，不按日複製。
2. 相同活動只保留資訊最完整的最新記錄。
3. 活動預告與回顧分開標示。
4. 沒有可核驗新內容的領域明確留白。
5. 月度頁成熟後才把獨有事實整理進年度編年。

固定領域包括編年史、日常／雜談、工坊／手工、百科／科普、禮儀和學術。
