# 2018 年 Kigurumi 編年史

> 2019-2025 年已完成。本輪依照「完成年份不重複、每次只向前整理一年」的規則整理 2018 年。可核驗材料集中在公共活動對着ぐるみ的安全與攝影規則，以及 animegao 面具製作配對服務的學位研究；沒有可靠日期的專門聚會不以推測補寫。

## 資料邊界

本文只把來源明確寫出的日期、場地、規則和論文元資料當作事實。AnimeJapan 是綜合動漫展，並非 animegao 專門活動；它的價值在於規則直接提到着ぐるみ、面具、視野、陪同、攝影與更衣。慶應義塾大學機構庫則確認一篇直接研究 animegao kigurumi 面具製作與訂單配對的 2018 學年度碩士論文。

## 主要紀事

### 3 月 24-25 日：AnimeJapan 2018 擴展着ぐるみ公共場地規則

AnimeJapan 2018 的公眾開放日於 3 月 24-25 日在東京 Big Sight 東 1-8 Hall 舉行。Cosplayers World 分布在東 3、東 8 Hall，提供付費 cosplay 登記、更衣室、寄存、室內外攝影區、早場更衣與巡遊。[^aj-outline][^aj-cosplay]

限制視野和行動的服裝只能在 cosplay 區域穿着、攝影需獲同意、更衣室禁止拍攝等基礎規則在 2017 年已出現，詳見[2017 年卷](../2017/index.md)。2018 年可單獨確認的更新是場地擴展至東 3、東 8 Hall，並在巡遊規則中要求着ぐるみ或遮擋視線的頭部裝具必須由一名陪同人員照看。[^aj-cosplay]

同頁延續拍攝前取得同意、不得強迫姿勢、不得在更衣室拍攝和使用寄存處等要求。本文不把這些延續條款重複計算為 2018 年新制度；本年的獨有節點是更大場地和明確的巡遊陪同責任。

### 2018 學年度：animegao 面具製作進入學位研究

慶應義塾大學機構庫收錄地曳はるか的碩士論文《アニメ顔着ぐるみマスク制作マッチングサービスの構築：マスク受注販売事業「キグルミ屋」の活動を通じて》，導師為杉浦一徳，出版者為慶應義塾大學大學院媒體設計研究科，形態為 x + 65 頁，並標為 2018 學年度媒體設計學第 689 號。[^keio][^ndl]

論文題名本身確認研究對象是 animegao kigurumi 面具製作、製作者配對與「キグルミ屋」受注銷售活動。由於機構庫沒有公開摘要，本文不推斷其方法、樣本或成效；只記錄一個可核驗的知識生產節點：面具製作供需與服務設計已成為正式碩士研究主題。

## 去重、空白與結論

本卷不重複 2019 年 FGO 官方着ぐるみ登場、2020 年取消與線上化、2021 年混合恢復，也不倒寫 2022-2025 年的專門活動、Doll Weekend、官方 greeting 與後續規則。2018 年未找到一手來源足以確認日期、地點和結果的專門 animegao 聚會，因此保留為空白。

2018 年最穩妥的結論有兩層：公共活動在既有視野、行動與攝影邊界上增加巡遊陪同責任；面具製作的訂單和製作者配對則進入大學學位研究。一個節點來自現場治理的增量，一個節點來自知識與產業組織，二者共同構成不誇大的年度記錄。
