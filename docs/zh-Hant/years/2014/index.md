# 2014 年 Kigurumi 編年史

> 2015-2025 年已完成。本輪依照「已完成年份不重複、每次只向前整理一年」的規則，只整理 2014 年。可核驗的一手材料集中在 AnimeJapan 2014 的主辦方閉幕後報告；沒有可靠日期、地點和結果的專門聚會不以推測補寫。

## 1. 取材邊界

本卷採用 AnimeJapan 主辦方保存的 2014 年閉幕後報告。報告可確認活動日期、場地、官方角色着ぐるみ互動，以及 Cosplayers World 的室內外攝影區和服裝租賃確實運行。[^aj-report]

AnimeJapan 是綜合動漫展，不是 animegao kigurumi 專門活動。報告把多啦 A 夢與 Keroro 軍曹等角色明確寫作「着ぐるみ」，但沒有把 Cosplayers World 的一般參與者識別為 animegao。本文因此把**官方角色着ぐるみ**與**可供全頭角色扮演使用的公共 cosplay 基礎設施**分開記錄，不把一般 cosplay 照片或全場人流推定為 animegao 參與證據。

## 2. 可核驗節點

### 3 月 22-23 日：Family Park 的角色着ぐるみ進入公開互動環節

AnimeJapan 2014 於 3 月 22-23 日在東京 Big Sight 東 1-6 Hall 舉行。主辦方報告記載，Family Park 的互動舞台安排多啦 A 夢、Keroro 軍曹等角色着ぐるみ依次登場。現場有家庭、成年動畫觀眾和情侶參加合照與握手；相鄰的紀念攝影區還陳列了蠟筆小新與浣熊拉斯卡爾等角色玩偶。[^aj-report]

這條記錄屬於官方角色 / mascot 語境，不等同於 animegao 玩家活動。其編年價值在於確認：角色着ぐるみ在 2014 年的綜合動漫展中已被組織成面向公眾、以合照和握手為核心的互動節目。

### 3 月 22-23 日：Cosplayers World 的室內外攝影基礎設施實際運行

同一份閉幕後報告確認，Cosplayers World 同時設置室內和室外攝影區。室內區提供與《艦隊Collection》《進擊的巨人》《魔法少女小圓》等作品聯動的佈景和背景板；室外區聚集動畫、遊戲與漫畫 cosplayer 和攝影者，並記錄到海外參與者。活動還在 ACOS 與 COSPA 協力下提供每小時 1,000 日圓的服裝租賃，降低首次 cosplay 的進入門檻。[^aj-report]

這些設施並未證明現場存在 animegao kigurumi，也沒有提供着ぐるみ參與人數。本文只把它們作為 2015 年「更衣室與室外區域較上一年擴大」之前的可核驗基線：2014 年已存在室內外攝影空間和公共參與服務，2015 年卷則保留擴容、收費、移動和攝影規則等新增事實。

## 5. 年度結論

2014 年可確認的不是一份 animegao 專門活動清單，而是兩種不同的公共實踐：官方角色着ぐるみ在 Family Park 承擔合照與握手互動；Cosplayers World 的室內外攝影區、作品佈景和服裝租賃則構成一般 cosplay 的公共參與基礎。兩者必須分開表述。主辦方報告能證明這些設施和節目實際運行，卻不能證明 animegao 參與者、專門聚會或社群規模；這些資料空白繼續保留。
