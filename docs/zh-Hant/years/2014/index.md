# 2014 年 Kigurumi 編年史

2014 年的材料從公共動漫展擴展到藝術攝影。Laurie Simmons 的作品檔案明確以 Kigurumi、Dollers 爲系列題目；AnimeJapan 則記錄官方角色互動與公共攝影設施。

## 年度重點

- **藝術攝影**：Laurie Simmons 的《Kigurumi, Dollers and How We See》標爲 2014 年。
- **3 月 22–23 日**：AnimeJapan Family Park 安排角色着ぐるみ互動。
- **公共攝影**：室內佈景、室外攝影區和服裝租賃實際運行。[^simmons][^aj-report]

## 年度紀事

### 3 月 22-23 日：Family Park 的角色着ぐるみ進入公開互動環節

AnimeJapan 2014 於 3 月 22-23 日在東京 Big Sight 東 1-6 Hall 舉行。主辦方報告記載，Family Park 的互動舞臺安排哆啦 A 夢、Keroro 軍曹等角色着ぐるみ依次登場。現場有家庭、成年動畫觀衆和情侶參加合影與握手；相鄰的紀念攝影區還陳列了蠟筆小新與浣熊拉斯卡爾等角色玩偶。[^aj-report]

這條記錄屬於官方角色 / mascot 語境，不等同於 animegao 玩家活動。它的編年價值在於確認：角色着ぐるみ在 2014 年的綜合動漫展中已被組織成面向公衆、以合影和握手爲核心的互動節目。

### 3 月 22-23 日：Cosplayers World 的室內外攝影基礎設施實際運行

同一份閉幕後報告確認，Cosplayers World 同時設置室內和室外攝影區。室內區提供與《艦隊Collection》《進擊的巨人》《魔法少女小圓》等作品聯動的佈景和背景板；室外區聚集了動畫、遊戲與漫畫 cosplayer 和攝影者，並記錄到海外參與者。活動還在 ACOS 與 COSPA 協力下提供每小時 1,000 日元的服裝租賃，降低首次 cosplay 的進入門檻。[^aj-report]

### 年內作品：Laurie Simmons 的 Kigurumi / Dollers 攝影系列

藝術家官網將《Kigurumi, Dollers and How We See》歸爲 2014 年，並分別列出《Yellow Hair/Red Coat/Umbrella/Snow》《Orange Hair/Snow/Close Up》等照片，以及同名展示的現場視圖。[^simmons]

該系列將角色面貌、假髮色彩、服裝、身體姿態及室內外場景用於藝術攝影。它屬於藝術家的作品與展示檔案，不能當作愛好者聚會報道；同一系列的多張照片合併爲一項年度作品記錄。

原圖和展示視圖可從藝術家官網查看。該站並未授予本站開放轉載許可，因此本卷提供原始作品入口。

## 年度小結

本年展示了兩種不同的公開呈現：官方角色在動漫展面向觀衆互動，Kigurumi / Dollers 也成爲藝術攝影題材。藝術系列、商業角色與普通 cosplay 場域分別記錄，保留各自的來源和性質。
