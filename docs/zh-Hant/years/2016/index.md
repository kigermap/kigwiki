# 2016 年 Kigurumi 編年史

2016 年重點整理 AnimeJapan 對遮面服裝的區域要求、攝影設施和寄存服務。主辦方閉幕後報告爲這些安排的實際運行提供依據。

## 年度重點

- **3 月 26–27 日**：公衆開放日使用東京 Big Sight 東 1–6 Hall。
- **臨時室外區**：主辦方報告確認這是本屆的新設施。
- **服務整合**：每日 1,000 日元登記包含更衣與寄存；早間更衣不開放寄存。[^aj-outline][^aj-cosplay][^aj-report]

## 年度紀事

### 3 月 26-27 日：AnimeJapan 2016 提供着ぐるみ可使用的公共 cosplay 基礎設施

AnimeJapan 2016 的公衆開放日於 3 月 26-27 日在東京 Big Sight 東 1-6 Hall 舉行。Cosplayers World 設置室內外攝影區、臨時室外攝影區、付費登記、更衣室和寄存服務。[^aj-outline][^aj-cosplay]

當年 cosplay 登記費爲每日 1,000 日元，包含更衣室和寄存服務；常規更衣時間爲 10:00-17:00，另有 7:00-9:00 的早間更衣時段，但早間不開放寄存。寄存服務運行至 16:30。[^aj-cosplay] 對需要運輸頭殼、服裝和附件的 kigurumi 參與者而言，這些並非附屬信息，而是公共參與能否成立的基礎條件。

規則明確把限制視野的覆面、面具、眼罩等服裝，以及行動困難的大型造型、着ぐるみ、拖地服裝或大型裝飾，限制在 cosplay 區域內穿着。攝影只能在指定區域進行，拍攝前須取得對方許可，不得強迫姿勢；更衣室內禁止拍攝，現場照片不得商用。[^aj-cosplay] 這份文本同時處理視野、移動、隱私、同意與影像用途，是 2016 年直接點名着ぐるみ的公共治理記錄。

### 閉幕後：官方報告確認臨時室外區與攝影設施實際運行

主辦方的閉幕後報告記錄，AnimeJapan 2016 三日總來場人數爲 135,323 人；這個數字覆蓋整個活動，不能拆算成 kigurumi 規模。報告同時確認，臨時室外 cosplay 區是當年的新設施，中午後聚集了大量 cosplayer 與攝影者；室內的官方作品攝影佈景也被 cosplay 參與者和普通觀衆使用。[^aj-report]

閉幕後報告使本卷能夠區分“規則頁上的計劃”與“實際投入運行的設施”。它仍不能證明某場專門 kigurumi 聚會或具體 animegao 角色出現，因此本文只把它寫成公共活動基礎設施的實施記錄。

### 當屆資料彙總：從早間換裝到攝影區域

| 時間或區域 | 本屆安排 |
| --- | --- |
| 7:00–9:00 | 早間更衣；此時不開放寄存 |
| 10:00–17:00 | 常規更衣服務 |
| 至 16:30 | 寄存服務 |
| 指定 cosplay 區 | 視野受限的覆面、面具，以及行動困難的大型着ぐるみ的穿着範圍 |
| 臨時室外區 | 閉幕後報告確認實際使用，午後聚集 cosplay 與攝影參與者 |

服務時間來自當屆規則，區域使用情況來自閉幕後報告。[^aj-cosplay][^aj-report] 兩者結合能夠說明頭殼、服裝與攝影裝備進入公共場域時所依賴的設施，尚不能識別其中每一位 animegao 參與者。

## 年度小結

本年可覈驗的重點是臨時室外區及整合後的更衣、寄存服務。專題工房發佈和同好聚會資料仍有缺口，本卷不以全場人數或未註明身份的照片代替。
